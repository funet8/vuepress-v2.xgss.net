## 什么是 nodecast-tv？

简单来说，`nodecast-tv` 是一个**自托管的 Web 应用程序**。 你只需要在 NAS 或服务器上通过 Docker 部署它，然后导入你的 `Xtream Codes` 或 `M3U` 播放源，就能在任何设备的浏览器里，享受媲美主流流媒体平台的观影体验。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782206438820.png?tx)

## 为什么星哥强烈推荐它？

1. **极致丝滑，告别卡顿** 针对大型播放列表做了深度优化，哪怕你的 M3U 源里有 **7000+ 个频道**，它也能通过虚拟滚动和批量渲染技术，保证列表滑动如丝般顺滑。
2. 功能全家桶，体验拉满
   - **直播电视 (Live TV)**：秒切频道，支持分类和搜索。
   - **电子节目指南 (EPG)**：自带 24 小时互动时间轴，看节目单一目了然。
   - **视频点播 (VOD)**：自动刮削电影和剧集的海报、元数据，打造私人影音库。
   - **多用户与收藏**：支持管理员/观众角色分离，收藏内容多端同步。
3. **轻量级，不吃服务器性能** 与传统的 IPTV 播放器不同，它**不在服务端进行视频转码**，而是直接把流推给你的浏览器，由浏览器进行硬件解码。这意味着你的 NAS CPU 占用率几乎可以忽略不计！

## 避坑指南：浏览器解码的“潜规则”

既然 `nodecast-tv` 依赖浏览器解码，那就不得不提一下各大浏览器对视频/音频格式的支持情况。这也是它和 `neTV`（服务端转码）最大的区别。

星哥给大家总结了**浏览器解码能力红黑榜**：

| 格式                | Chrome | Edge | Safari | Firefox | 星哥点评                                                     |
| :------------------ | :----: | :--: | :----: | :-----: | :----------------------------------------------------------- |
| **H.264**           |   ✅    |  ✅   |   ✅    |    ✅    | 万能格式，所有浏览器通吃。                                   |
| **H.265 (HEVC)**    |   ❌    |  ⚠️   |   ✅    |    ❌    | **Safari 亲儿子**；Chrome(macOS)靠硬解；Edge 需花 0.99 刀买扩展。 |
| **VP9 / AV1**       |   ✅    |  ✅   |   ⚠️    |    ✅    | YouTube 常用格式，主流浏览器支持良好。                       |
| **AC3/EAC3 (杜比)** |   ❌    |  ❌   |   ✅    |    ❌    | **苹果生态专属**，其他浏览器遇到杜比音轨可能会“哑巴”。       |

> 💡 **星哥建议**： 如果你用的是 Mac 或 iPad，直接用 **Safari** 体验最完美。 如果是 Windows 用户，遇到 H.265 或杜比音轨无法播放，建议在设置里开启 `nodecast-tv` 的 **FFmpeg 音频转码** 或 **流重封装** 功能来曲线救国。

## 飞牛 Docker 一键部署教程

废话不多说，我们直接上实操。星哥以飞牛 NAS 为例，推荐使用 `docker-compose` 方式，优雅且易于管理。

### 1. 准备目录

通过 SSH 登录飞牛，或者在目录中创建好数据持久化目录：

```
mkdir -p /volume1/docker/nodecast-tv/data
```

### 2. 编写 docker-compose.yml

在 `/volume1/docker/nodecast-tv/` 目录下新建一个 `docker-compose.yml` 文件，填入以下内容：

```
services:
  nodecast-tv:
    image: ghcr.io/technomancer702/nodecast-tv:latest
    container_name: nodecast-tv
    restart: unless-stopped
    ports:
      - "3124:3000"  # 左侧3124为访问端口，可自定义
    volumes:
      - ./data:/app/data
    environment:
      - NODE_ENV=production
      - PORT=3000
```

### 3. 启动容器

在终端中执行以下命令，一键拉起服务：

```
cd /volume1/docker/nodecast-tv
docker-compose up -d
```

## 上手配置与使用

### 第一步：注册与登录

在浏览器输入 `http://你的飞牛IP:3124`。首次访问会要求你注册一个账号，注册完成后即为**管理员（Admin）** 身份。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782226326207.png?tx)

### 第二步：添加 M3U 直播源

进入主界面后，点击右上角的 **Setting（设置）** -> **Add M3U**。

- **Name**：随便填，比如“我的IPTV源”。
- **URL**：填入你的 M3U 订阅链接。

> 🌍 **星哥拓展**： 如果你手里没有源，可以去 GitHub 搜 `iptv-org/iptv`，这是一个全球公开的 IPTV 频道合集。不过公共源稳定性看脸，星哥还是建议大家搭配自己购买的优质运营商源或私人源食用，体验更佳！

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782226528217.png?tx)

### 第三步：添加 EPG 节目单（可选）

为了让直播有“节目预告”功能，可以在 **Add EPG** 中填入对应的 XML 节目单地址。

### 第四步：开始观影

配置完成后，回到首页。

- 看直播：进入 **Live TV**，海量频道分类清晰，点击即播。
- 看大片：进入 **VOD** 区域，系统会自动为你整理好电影海报和剧集列表，配合收藏功能，简直就是一个网页版的爱奇艺/腾讯视频！



## 支持的流类型说明

最后，星哥再啰嗦一句关于**流格式**的兼容性，帮大家少走弯路：

- 🟢 **HLS (.m3u8)**：**最推荐！** 完美支持，自适应码率，网络抗抖动能力最强。
- 🟡 **MPEG-TS (.ts)**：支持，但需要在设置中开启“强制重封装”。
- 🔴 **RTMP / RTSP**：浏览器原生不支持，别白费力气了。
- ⚠️ **P2P/Acestream**：延迟较高，建议转换为 HLS 输出再导入。
