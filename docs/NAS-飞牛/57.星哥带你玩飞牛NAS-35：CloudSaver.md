## 一、CloudSaver 到底是个啥？

简单说：**云盘资源的搜索引擎**。

它把散落在各个网盘频道的资源汇总到一起，你只需要输入片名，它帮你从几十个频道里同时检索，找到直接给你转存链接。

支持的平台包括但不限于：阿里云盘、夸克、百度网盘、115、天翼、123云盘、UC、迅雷……

基本上你能叫得上名字的网盘，它都能搜。

## 二、部署前准备

我这里用的是 **飞牛 NAS**，群晖、绿联、极空间的朋友操作逻辑差不多，举一反三就行。



先做一件事：建文件夹。

打开文件管理，进入 `docker` 目录，新建一个 `CloudSaver` 文件夹。

然后在里面再建两个子文件夹：

- `config` → 存配置文件
- `data` → 存数据库

后面挂载要用。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1788167760681.png?tx)

## 三、Docker Compose

打开 NAS 上的 Docker 应用，切到 **Compose** 面板，新增一个项目：

- 项目名称：`cloudsaver`
- 路径：指向你刚建好的 `CloudSaver` 文件夹
- 来源：选择「创建 docker-compose.yml」

把下面这段贴进去：

```yaml
services:
  cloudsaver:
    image: jiangrui1994/cloudsaver:latest
    container_name: cloud-saver
    ports:
      - 3456:8008
    volumes:
      - ./data:/app/data
      - ./config:/app/config
    restart: unless-stopped
```

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1788167836267.png?tx)

> 端口 `3456` 是我自己定的，你随便改，别跟别的容器冲突就行。



点部署，等个十几秒，容器跑起来就完事了。

## 五、导入频道——这才是灵魂

刚装好的 CloudSaver 是个空壳子，搜啥都搜不到。

你需要给它"喂"频道源。

操作路径：**左侧齿轮图标 → 搜索"频道" → 批量导入**

频道配置去哪找？官方 GitHub 仓库里有整理：

👉 `https://github.com/jiangrui1994/CloudSaver`

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1788168310577.png?tx)

仓库里搜"频道"两个字，会跳转到一个语雀文档，里面是现成的 JSON 配置。

把那一整段 JSON 复制，粘贴到批量导入的框里，点 **「增量更新」**。

搞定。
