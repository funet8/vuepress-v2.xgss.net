## 一、easy-vdl能干啥？

先说结论，`easy-vdl` 定位是“综合直播视频订阅解析下载器”，它主要帮你解决三大痛点：

1. **全网视频解析下载**：支持抖音、小红书、B站、YouTube、TikTok、推特等主流平台。复制链接丢进去，直接解析下载。
2. **博主/频道无脑订阅**：*(注：此为 Pro 付费功能)* 支持订阅抖音博主/合集、B站UP主、YouTube频道等。系统会自动检测更新，新视频秒同步到 NAS。
3. **直播录制 + AI 高光切片**：*(注：此为 Pro 付费功能)* 监控各大平台直播间，开播即录。最牛的是，它能结合大模型（如 DeepSeek）分析弹幕情感，**自动切出高光片段**，生成标题和摘要，简直是短视频二创的神器！

**💡 飞牛 NAS 专属加分项：**

- 自动生成 Emby/Jellyfin 识别的 NFO 元数据文件，下载即入库。
- 完美支持 Intel/AMD 核显硬件加速转码。

*星哥提示：项目基础下载功能免费，但视频订阅、直播订阅、通用提取、直播回放等核心进阶功能需购买高级版授权，大家按需白嫖或支持作者哦！*

##  二、准备：目录与架构规划

飞牛自带的 Docker 面板非常友好，但动手前我们要先做好规划。

### **1. 确认 NAS 架构**

- **Intel x86 处理器**（飞牛主流机型）：使用镜像 `qq918652593/easy-vdl:latest`
- **ARM 架构**：使用镜像 `qq918652593/easy-vdl:arm64`（注意：ARM 镜像暂不支持核显硬件加速）

### **2. 规划存储目录**

在飞牛“文件管理”中建一个专属目录，例如 `/vol1/1000/docker/easy-vdl`，并在其下创建三个子文件夹：

- `downloads`：存放视频和直播录像（建议放在大容量机械硬盘池）。
- `logs`：存放运行日志。
- `database`：存放数据库（体积不大但读写频繁，**强烈建议放在 SSD 缓存盘**）。

### **3. 规划端口**

默认 Web 端口是 `888`，如果和飞牛其他服务冲突，可以改成 `8888` 或其他空闲端口。



## 三、一键部署：Docker Compose 实操

### Docker Compose部署

打开飞牛桌面的“Docker”应用，进入“项目”或“Compose”页面，点击“新建”。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782784635218.png?tx)

项目名填 `easy-vdl`，将下面的 YAML 代码粘贴进去：

```yaml
version: '3.8'

services:
  easy-vdl:
    # x86_64 设备使用 latest，ARM64 设备请改为 arm64 标签
    image: qq918652593/easy-vdl:latest
    container_name: easy-vdl
    ports:
      - "888:80"                      # 888 为外部访问端口，可按需修改
      - "8001:8001"                   # 企业微信 Bot 回调端口（可选）
    mem_limit: 2g                     # 推荐 4G，小规模订阅可降为 2G
    memswap_limit: 4g
    # 【x86硬件加速，ARM设备请删除 devices/cap_add 块】
    # Intel/AMD 核显（默认配置，NVIDIA 用户请改用下方注释块）：
    devices:
      - /dev/dri:/dev/dri             # Intel/AMD 核显硬件加速映射
    # NVIDIA 显卡请改用以下配置（注释上方 devices，取消下方注释）：
    # deploy:
    #   resources:
    #     reservations:
    #       devices:
    #         - driver: nvidia
    #           count: all
    #           capabilities: [gpu]
    cap_add:
      - PERFMON                       # GPU 仪表盘监控负载支持
    volumes:
      - ./downloads:/app/downloads    # 视频与媒体下载保存路径
      - ./logs:/app/logs              # 程序运行日志
      - ./database:/app/database      # 数据库与全局配置路径
    environment:
      - EASY_VDL_PORT=80
      - PUID=1000                     # 推荐修改为您宿主机用户的 UID/GID，防止出现 Permission denied 错误
      - PGID=100
      - EASY_VDL_ADMIN_USERNAME=admin # 预设管理员用户名
      - EASY_VDL_ADMIN_PASSWORD=admin123456 # 预设管理员密码
      - TZ=Asia/Shanghai
    restart: unless-stopped
```

### 传统的 Docker Run 部署指令

```
# x86_64 - Intel/AMD 核显（支持硬解与 GPU 监控）
docker run -d --name easy-vdl -p 888:80 -p 8001:8001 \
  --memory=4g --memory-swap=4g \
  --device=/dev/dri:/dev/dri \
  --cap-add PERFMON \
  -v $(pwd)/downloads:/app/downloads \
  -v $(pwd)/logs:/app/logs \
  -v $(pwd)/database:/app/database \
  -e EASY_VDL_PORT=80 -e PUID=1000 -e PGID=100 -e TZ=Asia/Shanghai \
  -e EASY_VDL_ADMIN_USERNAME=admin -e EASY_VDL_ADMIN_PASSWORD=admin123456 \
  --restart always \
  qq918652593/easy-vdl:latest

# x86_64 - NVIDIA 显卡（需提前安装 nvidia-container-toolkit）
docker run -d --name easy-vdl -p 888:80 -p 8001:8001 \
  --memory=4g --memory-swap=4g \
  --gpus all \
  --cap-add PERFMON \
  -v $(pwd)/downloads:/app/downloads \
  -v $(pwd)/logs:/app/logs \
  -v $(pwd)/database:/app/database \
  -e EASY_VDL_PORT=80 -e PUID=1000 -e PGID=100 -e TZ=Asia/Shanghai \
  -e EASY_VDL_ADMIN_USERNAME=admin -e EASY_VDL_ADMIN_PASSWORD=admin123456 \
  --restart always \
  qq918652593/easy-vdl:latest

# ARM64 设备（如群晖 ARM 架构、Mac M1/M2 系列）
docker run -d --name easy-vdl -p 888:80 -p 8001:8001 \
  --memory=4g --memory-swap=4g \
  -v $(pwd)/downloads:/app/downloads \
  -v $(pwd)/logs:/app/logs \
  -v $(pwd)/database:/app/database \
  -e EASY_VDL_PORT=80 -e PUID=1000 -e PGID=100 -e TZ=Asia/Shanghai \
  -e EASY_VDL_ADMIN_USERNAME=admin -e EASY_VDL_ADMIN_PASSWORD=admin123456 \
  --restart always \
  qq918652593/easy-vdl:arm64
```

### 星哥独家避坑指南

1. **权限问题（重中之重）**：`PUID=1000` 和 `PGID=1001` 是飞牛默认用户组。如果你用了其他账号，请在 SSH 里执行 `id 你的用户名` 获取真实 ID 并替换，否则会导致数据库初始化失败！
2. **内存分配**：`mem_limit: 4g` 适合中重度订阅用户。如果只是偶尔下载，改成 `2g` 也足够。
3. **镜像拉取**：国内拉取 Docker Hub 偶尔会抽风，如果卡住，记得在飞牛 Docker 设置里配置阿里云或 DaoCloud 等镜像加速器。



## 四、首次登录与初始化配置

容器启动后，浏览器访问 `http://飞牛IP:888`。

1. **登录系统**：使用你在 Compose 中设置的账号密码登录，下拉阅读并同意《免责声明》。
2. **配置 Cookie（关键）**：进入“设置” -> “Cookie 管理”。想要下载抖音点赞列表、B站私密合集等需要登录态的内容，必须在这里配置对应平台的 Cookie。
3. **获取 API Token**：同样在设置中获取，这是后续配合浏览器插件、iOS 快捷指令一键下载的必备凭证。

## 四大实战玩法，解锁 NAS 新姿势

### 场景 1：临时解析下载
最基础的玩法。复制某音的视频链接，粘贴到首页输入框，点击解析。选择清晰度后下载，文件直接落入 `downloads` 目录。勾选“生成 NFO”，Emby 就能直接刮削海报了。



### 场景 2：无脑订阅 UP 主 *(需 Pro 授权)*

进入“订阅”页面 -> “新增订阅”。粘贴博主主页链接，设置策略（如：仅下载新视频/同步历史、保留画质等）。保存后，系统会像 RSS 一样在后台默默帮你把新视频全搬回 NAS。



### 场景 3：直播录制 + AI 自动切片 *(需 Pro 授权)*

在“直播回放”添加直播间。主播一开播，系统自动录制并抓取弹幕。下播后，如果你配置了 DeepSeek 等大模型 API Key，它会自动分析弹幕热度，**把高光时刻切出来，连标题和摘要都给你写好**，打包成 ZIP。做切片号的星友，这功能绝对值回票价！



### 场景 4：浏览器插件“无感”下载
去 GitHub Releases 页面下载浏览器插件，安装到 Chrome/Edge，填入 NAS 地址和 API Token。以后在网页上看到喜欢的视频，点一下插件图标，视频就直接飞进 NAS 了，丝滑无比！





## 星哥碎碎念

折腾只是第一步，用好才是关键。这几个细节大家一定要注意：

- **外网访问安全**：想在公司或外面访问？千万别直接把 888 端口暴露在公网！建议使用飞牛自带穿透、Tailscale/Zerotier 组网，或者至少配置 **反向代理 + HTTPS + 强密码**。
- **小心硬盘爆满**：视频订阅是个“吃硬盘大户”。星哥订了 10 个博主，一个月就攒了 200G。**一定要在设置里配置保留策略**（比如只保留最近 30 天或最新 50 个视频）。
- **Cookie 过期**：各平台的 Cookie 都有有效期。如果发现订阅突然不更新了，别慌，大概率是 Cookie 失效了，去设置里手动刷新一下即可。
- **平滑升级**：作者更新很勤快。升级时只需在飞牛 Docker 面板找到该项目，点击“重新部署”，它会自动拉取最新镜像，挂载的数据都在，不会丢失。
