## 四、跟着星哥来实操

### Step 1 ｜ 开通腾讯云账号并完成实名（已操作可以忽略）

- **操作**：打开 https://cloud.tencent.com 注册 / 登录，进入「账号中心」完成实名认证。
- **为什么必须实名**：调用付费 AI 能力前，腾讯云要求账号通过实名，否则无法开通服务、无法创建密钥。
- **✅ 验证标准**：能正常进入控制台首页，左上角显示已实名。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1786697678394.png?tx)

### Step 2 ｜ 在控制台开通你要用的 AI 服务

Skill 只是"调用通道"，背后真正的 AI 能力需要在腾讯云控制台**先开通**。

以最常见的三类为例：

- **OCR 类**：进入「文字识别」→ 开通 `通用文字识别（高精度版）`、`表格识别 V3`、`实时文档抽取 Agent`
- **语音类**：进入「语音合成」开通 TTS；进入「语音识别」开通 ASR
- **创意类**：进入「3D 视觉创作（ai3d）」开通混元生 3D

> 💡 **免费额度提醒**：发票识别每月 1000 次免费、表格识别 V3 每月 1000 次免费、文档抽取 Agent 每月 1000 次免费；TTS / ASR / 3D 也各有免费额度。做新手练习完全够用，不会产生费用。

- **✅ 验证标准**：对应服务页显示"已开通"，且能看到「免费资源包」已下发。

### Step 3 ｜ 创建 API 密钥（SecretId / SecretKey）

Skill 调用腾讯云接口时，靠这对密钥做权限校验。

- **操作**：控制台 → 「访问管理」→「API 密钥管理」→「新建密钥」，生成 `SecretId` 和 `SecretKey`。
- **⚠️ 安全红线**：
  - `SecretKey` **只在创建时显示一次**，立刻复制保存到本地密码管理器；
  - **绝不要**写进代码仓库、提交到 GitHub、或贴进公开文章。
- **✅ 验证标准**：拿到一对 `SecretId` / `SecretKey`。

### Step 5 ｜ 配置密钥，让 Skill 真正能调通

装好 Skill 只是"装了电话"，还得"插 SIM 卡"才能打通——把 Step 3 的密钥交给 WorkBuddy。

**推荐方式（持久化，一次配置长期有效）**：在 WorkBuddy 的**技能配置面板**里，把 `SecretId` / `SecretKey` 填入对应字段，完成权限绑定。之后该 Skill 的所有调用都自动带凭证，不用每次重复输入。

**临时 / 跨平台方式（环境变量）**：适合想快速验证、或在其它终端复用：

```powershell
# Windows PowerShell
$env:TENCENTCLOUD_SECRET_ID = "你的SecretId"
$env:TENCENTCLOUD_SECRET_KEY = "你的SecretKey"
```

```bash
# Linux / macOS
export TENCENTCLOUD_SECRET_ID="你的SecretId"
export TENCENTCLOUD_SECRET_KEY="你的SecretKey"
```

> ⚠️ 注意：PowerShell 的 `$env:` 只对**当前终端会话**生效，关掉重开就丢了；要稳定使用请走配置面板持久化。

- **✅ 验证标准**：再次调用 Skill 时，不再弹出"缺少密钥 / 无权限"的提示。

## 五、Bonus：把两个 Skill 串成小流水线（多 Skills 协同）

跑通单个 Skill 后，稍微往前一步就是活动最加分的"多 Skills 协同"。比如一个**文档阅读助手**：

> 上传一份 PDF 合同 → OCR 提取全文 → 生成要点摘要 → TTS 合成一段语音播报

在 WorkBuddy 里可以连续下指令，或由它自动编排：

```
1. 用 tencentcloud-ocr-extractdocagent 把这份合同的结构化字段抽出来
2. 基于抽取结果，给我一段 200 字的风险摘要
3. 用 tencentcloud-tts 把这段摘要合成语音
```

一条指令链下来，原本要读完 + 手写纪要 + 再找配音工具的活，Agent 一次跑完。





## 六、新手避坑清单（最常踩的 5 个）

1. **没先开通云服务就装 Skill** → 调用时报"无权限 / 服务未开通"。记住：Skill 是通道，服务要在控制台先开。
2. **密钥泄露 / 写进仓库** → `SecretKey` 只显示一次，务必本地保管，别提交代码。
3. **环境变量会话失效** → PowerShell `$env:` 关窗口即丢，长期用请走配置面板持久化。
4. **一上来就搞复杂多 Skill 编排** → 建议先单 Skill 跑通，再叠加，否则排错成本翻倍。
5. **直接把原始大图 / 长音频喂给 AI** → 参考电网巡检案例的经验："别让 AI 直接面对原始数据"。先预处理（如人像分割抠图、裁剪无关区域），识别率和效果会明显提升。
