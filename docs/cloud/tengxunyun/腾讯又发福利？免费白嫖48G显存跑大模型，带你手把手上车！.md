##  使用限制

在教大家怎么搞之前，星哥得先给大家泼点冷水。免费的往往是最贵的，CNB的算力虽然香，但限制也不少。

大家一定要心里有数，别指望拿它当免费的生产力工具：

1. **额度限制**：每月送 **1600核时**。如果你开的是48G显存的顶配环境（大概占48核），满打满算 **只能跑33个小时左右**。
2. **回收机制**：环境最长只能连续用 **4小时**；如果你切出去干别的事，**离线10分钟系统就会自动回收容器**。（评论区还有老哥说每日凌晨会强制回收，大家记得及时保存数据）。
3. **资源抢占**：毕竟是免费的，高峰期可能会遇到“无可用GPU分配”的情况，得看脸。

> 💡 **星哥建议**：把它当成一个 **“云端的高级玩具”** 或者 **“新模型测试床”**。比如最近很火的 Gemma-4-12B 或者 Qwen3.6，拿来测测能力、接个本地客户端聊聊天，那是相当惬意。

## 星哥手把手实操：四步搞定专属API

废话不多说，直接上干货。整个过程不需要你懂复杂的Linux命令，只要会点鼠标、会复制粘贴就行。

### 1、注册
1. **微信扫码登录**：打开 [cnb.cool](https://cnb.cool)，直接微信扫码一键登录。不用搞什么海外手机号，隐私安全也有大厂背书。
2. **创建“组织”**：CNB的规矩是仓库必须挂在组织下。随便起个名字（系统会校验是否被占用），创建一个属于你的Organization。



### 2、抄作业（Fork仓库）
3. **找现成轮子**：进入官方的 Ollama 一键启动仓库，比如星哥用的 `cnb.cool/ai-models/Ollama/OneClick/qwen3.6`。这里还有很多其他模型，看上哪个点哪个。
4. **一键Fork**：点击右上角的 `Fork`，选择你刚才创建的组织，把整个仓库搬到你自己的地盘。页面跳转后看到代码都在，说明搬运成功。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1783994199652.png?tx)

### 3、启动
唤醒云端电脑：在仓库右上角找到 **「云原生开发」** 按钮，点下去！等个几十秒，系统会给你开一个网页版的 VS Code。这体验，简直就像在浏览器里装了一台高配电脑。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1783994263638.png?tx)



一键跑模型：点开左侧的 `README.md` 看看说明。然后在底部的 Terminal（终端）里，敲下这行灵魂代码：
```bash
ollama run qwen3.6
```
*(注：想跑别的模型，把后面的名字换掉就行)*

### 4、外网穿透
8. **获取专属API**：模型跑在网页里怎么行？我们要把它接到手机或者本地客户端上！
   在网页版VS Code的顶部菜单找到 **PORT（端口）** 页面，输入 `11434`，点击 `Add Port`。
   系统会立刻生成一个**全球唯一、公开访问的URL链接**。
   
   > ⚠️ **星哥提醒**：这个链接是你私人的，别到处乱发。有了它，你的云端大模型就彻底“活”了。

## 进阶玩法

拿到了专属的 URL 链接，好戏才刚刚开始。

**接入本地客户端（如 WorkBuddy、ChatBox）**
打开你常用的第三方AI客户端，找到 Ollama 配置项，把刚才拿到的 URL 填进去。**API密钥（Key）随便填个123就行**，因为CNB默认没开鉴权。配置完，你就能用着腾讯的48G显卡，在本地流畅地跟大模型对线了。
