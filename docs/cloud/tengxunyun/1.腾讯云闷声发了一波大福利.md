## 香不香？

我玩过不少平台的免费档，大部分是这几种套路：

- **"注册送 5 美元，30 天过期"** —— 你还没来得及认真测，额度就没了
- **"永久免费，但每分钟限 3 次调用"** —— 说是免费，实际根本没法正经用
- **"送 100 万 Token，7 天内有效"** —— 逼你一周内疯狂消耗，跟促销快过期似的

TokenHub 这次最让我舒服的两点：

1. **有效期 1 年**。从领取那天开始算，不是从活动开始算。你现在领，明年今天才过期。不用赶，想起来了拿出来玩玩就行。

2. **每个模型独立 100 万**。不是总共 100 万让你自己分，而是 **每个模型各给 100 万**。你想把 DeepSeek、Kimi、GLM 全试一遍，各烧 100 万，互不干扰。这就很舒服了——可以拿同一个任务喂给不同模型，横向比效果。

另外提一嘴：TokenHub 用的是 **OpenAI 兼容协议**。

也就是说你现在用的 ChatGPT 客户端、代码编辑器里的 AI 插件、各种支持自定义 API 的工具，**把 Base URL 和 Key 一换就能直接切过去**。不用改代码，不用装 SDK。

只是现在100万的token星哥一天就搞完了！

## 怎么领

别担心流程复杂，我走了一遍，全程不超过 5 分钟。

### 第一步：注册 + 实名

打开 [腾讯云 TokenHub](https://cloud.tencent.com/product/tokenhub)，注册账号、完成实名认证、开通 TokenHub 服务。

实名这步是硬要求，没得跳过——不过国内云厂商都一样，不实名连账号都登不进去。



![img](https://imgoss.xgss.net/picgo-tx2026/11614e636cda0839d1e24363ee6ec229.png?tx)



### 第二步：一键领取

进 [模型广场](https://console.cloud.tencent.com/tokenhub/models)，右上角有个醒目的「**新用户福利免费体验**」按钮。点开弹窗，把想要的模型全勾上，点「立即领取」。

[https://console.cloud.tencent.com/tokenhub/models](https://console.cloud.tencent.com/tokenhub/models)

![img](https://imgoss.xgss.net/picgo-tx2026/b1ff6f7d0d38ea12c6e9b7dc9551f714.png?tx)

**建议全选。** 反正每个模型的额度是独立的，你不领白不领。也别担心"领了不用浪费"——官方文档写了，过期没用的额度自动失效，你没有任何损失。

### 第三步：创建 API Key

进 [API Key 管理](https://console.cloud.tencent.com/tokenhub/apikey)，选个地域，创建一个 Key。创建时可以设这个 Key 能访问哪些模型，我建议先全开，后面再按需收紧。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1793700687459.png?tx)

**关键信息记一下：**

| 配置项       | 值                                    |
| ------------ | ------------------------------------- |
| Base URL     | `https://tokenhub.tencentmaas.com/v1` |
| API Key      | 你刚创建的那个                        |
| 模型 ID 示例 | `deepseek-v4.1-flash-1017`            |

模型显示名和实际填写的 model ID 有一个对照表，在 [官方模型列表](https://cloud.tencent.com/document/product/1823/130051) 里能查到。不过常用的那几个，基本上就是 `模型名-版本号` 的格式，不难猜。

配好以后，随便发一句"你好"，能收到正常回复就说明通了。

再去控制台的用量页面看一眼，确认走的是免费额度而不是后付费。


## 两个时间点记一下

- **活动截止：2026 年 12 月 31 日**。在这个日期之前注册并领取就行。
- **额度有效期：领取后 1 年**。比如你今天领的，有效期到 2027 年 11 月 3 日。

还有几条规则：

- 每个主账号、每个模型只能领一次。
- 调用时优先扣免费额度，用完才走后付费。
- 没开启后付费的话，免费额度用完就自动停了——不用担心产生意外账单。



## 免费额度用完了怎么办？

免费额度用完了怎么办？两条路：

1. **开了后付费，继续按量计费**。TokenHub 的按量价格比直连模型厂商略高一些（毕竟多了一层聚合和治理），但好处是 **一个 Key 通吃所有模型**，不用挨个去各厂商注册、充值、管 Key。如果你同时用 3-5 个模型，这个管理成本省下来挺值。

2. **如果你只用一两个模型**，直接去模型厂商官网开账号可能更划算。毕竟腾讯云这层多了一层转发成本。

不过话说回来——**有 100 万免费额度在前面挡着**，大多数个人用户短时间内根本到不了"需要付费"那一步。先白嫖，嫖完了再想掏钱的事，不迟。

说到云厂商账单——我在腾讯云上跑了几台轻量服务器，每个月的账单从没超过一顿饭钱。如果你也在腾讯云上有消费，不妨看看有没有优化空间。阿里云那边我有几个朋友用返佣链接省了不少，入口我放在文末了。




## 100万Token能做什么

100 万 Token 拿到手，除了"跟 AI 闲聊"还能干点啥：

- **横向评测**：同一个 prompt 分别发给 DeepSeek、Kimi、GLM、混元，看看谁回答得最好。尤其写代码场景，不同模型差异很大。
- **搭个本地 Agent**：把 TokenHub 的 API 接进你的自动化工具里，让 AI 帮你定时处理数据、生成报告。
- **测试新模型**：像 DeepSeek V4.1 Flash 这种刚出的版本，自己跑一跑比看测评文章靠谱多了。
- **教学演示**：如果你带团队或给学生讲课，有免费的 API 额度就随便 demo，不用每次都心疼 Token。

**两个提醒，很重要：**

1. **别把带额度的 Key 暴露到公网**。TokenHub 的 Key 跟所有 API Key 一样，泄露了就是别人帮你花额度。写教程截图的时候记得打码。

2. **别装来路不明的"破解版"客户端**。市面上有打着"免费接 DeepSeek"名号的第三方客户端，实际上可能是在代理你的请求、偷你的 Key。用官方 API + 正经客户端，安全第一。
