## 核心教程

很多自动化脚本最劝退的一步就是“抓包”，但星哥给大家找的这条路子，**完全不需要抓包！完全不需要抓包！完全不需要抓包！**（重要的事情说三遍）

### 第一步，获取自己的token

**1. 环境变量名称：**
`WORKBUDDY`

**2. 变量值格式：**
`ACCESS_TOKEN#UID#备注`
*(注：如果是多账号，用换行符隔开即可)*

**3. 去哪里找 ACCESS_TOKEN 和 UID？**

你只需要在 Windows 电脑上登录一次 WorkBuddy 客户端，然后直接去本地文件里“偷”数据：

👉 **文件路径（直接复制到window的文件夹中）：**

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1787554036208.png?tx)

`%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info`

3. 找到 `workbuddy-desktop.info` 这个文件，**右键用“记事本”打开**。
4. 在里面找到 `auth.accessToken` 和 `account.uid` 对应的值，复制下来填到青龙面板里就行了。

示例：

```
  "auth": {
    "accessToken": "abcdsdfadsfasdfasdfasdfasdf.......",  记录这个值
    "expiresIn": 5184000,

  "accounts": [
    {
      "uid": "888888888888.....", 记录这个值
```

## 定时规则与避坑指南

脚本配置好后，定时规则建议设置为 **一天 1-2 次**，比如早上 9 点和晚上 8 点，足够覆盖签到了。

不过有几个坑，星哥得提前给大家避一下：

**1. Token 会过期**
`ACCESS_TOKEN` 理论上差不多 **60天** 会过期。过期后脚本会报错，到时候记得重新登录客户端，再去文件里拿一次新的 Token。

**2. 积分有保质期**
签到领到的积分有效期只有 **30天**！大家记得尽早用掉，别攒着攒着就清零了。
