## 方式 2：HyperFrames + Remotion 全自动完整短视频（口播 / 知识号首选，推荐）

这套就是大家说的 “一键成片” 链路，4 个核心 Skill：

- **HyperFrames**：写脚本、分镜、规划整条视频（台词、画面、时长）
- **ElevenLabs / TTS**：旁白配音
- **Remotion**：代码渲染，把图片、文字、字幕、动画拼成 MP4
- **Captions**：自动字幕、对齐时间轴、高亮关键词

## 常见坑

1. 只说 “做一个好看视频” 大概率翻车，动作、镜头、比例必须写清楚
2. Remotion 成片第一次渲染容易报错：让它检查 Remotion 代码、降低分辨率或者缩短单镜头时长
3. 人物容易变脸：固定角色描述，每一条画面提示词带上统一人设
4. 没有声音：指令里明确加上 “添加 BGM / 旁白音频”
