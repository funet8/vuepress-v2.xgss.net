## 视频制作Skills

### 1.HyperFrames：一句话搞定动效视频
**👉 适合：图文转视频、知识科普、产品宣传**

这个技能非常实用。你只需要告诉 Codex 视频主题，它就能用 HTML、CSS 和动画帮你生成产品介绍、动态海报或者 PPT 风格的视频，最后直接渲染成 MP4。

如果你手里有一堆好文章、好推文，用这个工具把它们快速“视频化”，流量直接翻倍。

star数：38.4k+

GitHub：`https://github.com/heygen-com/hyperframes`



### 2.video-use：你的私人“无情”剪辑师
**👉 适合：真人口播、教程、采访剪辑**

拍口播视频最烦什么？卡壳、嘴瓢、口头禅！
把素材扔给这个 Agent，它能自动帮你删掉停顿、错误片段和“呃、啊”这种废话。甚至连字幕、音频处理、调色和画面动效都能一并搞定。

**点评**：经常做口播和教程的博主，装上它，你的剪辑时间至少省一半。

star数：18k+

**GitHub**：`https://github.com/browser-use/video-use`



### 3.Generative Media Skills：AI 视频生成“全家桶”
**👉 适合：AI 广告、UGC 视频、音乐短片**

这是一个覆盖图片、视频和音频生成的综合工具箱。它可以调用各种 AI 模型，帮你做产品广告或者社交媒体短片。

**点评**：想玩转 AI 生视频的各种骚操作，从这个仓库开始准没错。（注：部分功能需配置 MuAPI，会产生一定的生成费用，大家按需使用）。

star数：3.9k+

**GitHub**：`https://github.com/SamurAIGPT/Generative-Media-Skills`



### 4.videocut-skills：最懂中文的剪辑 Agent
**👉 适合：国内短视频创作者**

用 Claude Code Skills 做的视频剪辑 Agent

前面几个工具对中文的理解可能差点意思，但这个专门面向中文创作者。它能让 Agent 准确理解你的中文剪辑需求，帮你处理素材、字幕和短视频流程。

**点评**：习惯用 Claude Code 或其他 Agent 剪视频的国内老哥，重点研究一下这个。

star数：2.8k+

**GitHub**：`https://github.com/Agentchengfeng/chengfeng-videocut-skills`



### 5.seedance2-skill：即梦（Seedance）的“最强辅助”
**👉 适合：AI 短剧、高质量 AI 镜头生成**

你只管提供脑洞，它会帮你设计逐秒分镜、人物动作、运镜、对白和音效。生成的专业提示词，可以直接喂给即梦 Seedance 2.0 来生成核心镜头。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785291910930.png?tx)

**点评**：它负责写提示词和分镜，即梦负责生成画面，配合起来做 AI 短剧简直绝了。

star数：3k+

**GitHub**：`https://github.com/dexhunter/seedance2-skill`
