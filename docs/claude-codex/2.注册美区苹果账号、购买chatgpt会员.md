## 三、养号阶段

1. 在苹果手机上登录AppStore，如果之前有安装cha-t-g-p-t把之前的app卸载掉
2. 在AppStore里面下载新的cha-t-g-p-t app
3. 用苹果账号同步登录cha-t-g-p-t
4. 用英文每天在web端、app端问cha-t-g-p-t几个问题，持续个三、四天或者1个星期
