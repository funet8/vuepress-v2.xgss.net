## 一、它不是又一个 Claude Code

先说清楚一件事。

市面上做 Agent 的产品，十有八九是同一个套路：模型调工具，工具干活，干完吐结果。流程写死，你只能用，不能改。

DeepSeek Harness 不走这条路。

它的核心哲学就八个字：

> **Everything is a Plugin.**
> 一切皆插件。

模型是插件，工具是插件，文件系统是插件，沙箱是插件，甚至连 Agent Loop 本身——也是插件。

什么意思？

**Agent 不再是一个铁板一块的黑箱，而是一堆积木。**

你可以拆开，可以替换，可以重新组合。

想换个模型？拔下来换一个。想加个新工具？插上去就行。想改执行逻辑？Agent Loop 本身就是个可替换模块。

这个思路，说实话，我在其他开源项目里没见过这么彻底的。

## 二、如何安装DeepSeek Harness

为了方便以下把DeepSeek Harness 称为"DSH"。

### 1.通过 npm 运行

官网下载：[https://nodejs.org/zh-cn/](https://link.wtturl.cn/?target=https%3A%2F%2Fnodejs.org%2Fzh-cn%2F&scene=im&aid=497858&lang=zh)

推荐版本：**Node.js 24 LTS**
安装完成后新开终端，验证：

```
node -v
npm -v
```

输出版本号即成功。

>
> Windows / Mac / Linux 通用。

安装 `Node.js`，然后运行：

```
npx @deepseek-ai/dsh web
再输入
dsh web 
打开浏览器
```

该命令会启动 Web UI，默认地址为 `http://127.0.0.1:3080`

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1786934414635.png?tx)



### 2.从源码运行

如需从仓库源码运行：

```
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

## 五、源码里藏了四个狠设计

### 1.Agent 本身也是插件

传统 Agent 框架里，Agent 是"老大"，所有东西都塞它肚子里。

Harness 反过来：**Agent 只是 Context 里的一个能力模块。**

底层用了一个叫 Cordis 的开源小框架，所有东西通过 `ctx.plugin()` 注册。要什么加载什么，不要就卸掉。

不造轮子，直接用现成的插件机制，这点挺务实。



### 2.依赖注入 + 自动清理

插件之间不互相调用，而是声明"我需要什么"，框架负责把东西送过来。

更爽的是资源管理。定时器、事件监听、网络连接……全部跟插件生命周期绑定。加载时创建，卸载时自动 cleanup。

**不用自己记着清理，也不会内存泄漏。**

这也是热替换能跑通的基础。



### 3.会话轨迹可追溯、可回放、可 fork

很多 Agent 跑完就完了，中间调了什么工具、返回了什么，全靠猜。

Harness 把每个会话拆成一条不断追加的事件序列。每个动作都有记录。

出了问题，顺着轨迹往回查就行。

更骚的操作：**你可以从某个 checkpoint fork 出来，走另一条路重新跑。**

就像 Git 的分支一样，但对象是 Agent 的执行过程。

---

### 4.能力接缝设计

拿 Bash 执行举例。

Harness 没有把"在哪跑命令"写死。它定义了一个统一接口，具体实现可以是本机 Shell、Docker Shell、远程 Shell……

上层 Agent 只管调接口，底层随便换。

**这就是为什么它能把那么多子系统拆成独立插件——因为各模块之间靠接口连接，不是硬编码绑死的。**





## 目前的缺点

### **1.它现在还是个半成品。**

官方自己说了，目前是开发者预览阶段，后续会有破坏兼容性的改动。

装完你会发现，界面是个空壳。传文件、识图、粘贴……啥都没有。

**需要啥功能，自己装插件。**



### **2.插件生态是把双刃剑。**

HN 上已经有人吐槽了：社区插件这条路，头几个月热闹，后面维护就是噩梦。

这不是 DSH 独有的问题，是所有插件化平台都要面对的宿命。但确实得提前打个预防针。



## 推荐安装插件

既然装完是空壳，那哪些插件得先安排上？

我按优先级分了三档：

**🔥 第一梯队（不装等于白装）**

- **ModLens**：识图能力
- **dsh-at-file**：输入框打 @ 引用文件
- **dsh-paste-input**：支持 Ctrl+V 粘贴、拖拽文件
- **dsh-office**：读写 docx / pdf / pptx
- **dsh-browser-panel**：内嵌浏览器，让 Agent 操作网页
- **dsh-computer-use**：Agent 操作桌面（仅 macOS）

**⚡ 第二梯队（体验质变）**

- **safe-find-dsh-plugins**：说需求自动帮你找插件
- **dsh-web-ui**：任务看板、Git 集成、手机远程、Token 统计全家桶
- **dsh-genui**：回复里直接渲染图表和组件
- **dsh-turn-rewind**：一键回退到上一步
- **dsh-message-edit**：编辑已发消息、重新生成

**🧩 第三梯队（进阶玩法）**

- **dsh-agent-teams**：多 Agent 协作
- **dsh-memory-evolve**：跨会话长期记忆
- **dsh-llm-fallbacks**：模型挂了自动切备用
- **dsh-feishu-bot**：接飞书机器人

目前 GitHub Topics 页面已经收录了 **1000+ 插件**，还在快速增长。
