今天给大家盘点一下，**Codex 中最值得安装的 11 个神级 Skills**。从底层逻辑到实战场景，一篇文章给你讲透。建议先收藏，再照着装！



## 什么是 Codex Skills？

别被“技能”这个词唬住，用大白话说，**Skill 就是一套以 `SKILL.md` 文件为核心的“外挂指令包”。**

它最牛的地方在于 **“渐进式加载”** 机制：
Codex 启动时，只会读取所有已安装 Skill 的名字和简介（大概只占 2% 的上下文预算）。只有当你触发特定任务时，系统才会把对应的完整指令加载进来。如果不匹配，绝不占用一丁点内存。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1783951307879.png?tx)

**这能带来什么好处？**
1. **极其省 Token**：相比传统把一堆 Prompt 塞进上下文的做法，Skill 能帮你**节省 80% - 95% 的 Token 消耗**。
2. **跨平台通吃**：这是个开放标准。你写好的 `SKILL.md`，不仅 Codex 能用，无缝切换到 Claude Code、Cursor、GitHub Copilot 也照样生效。

##  怎么装？去哪找？

安装 Skill 其实非常简单，星哥最推荐用官方的 `skill-installer` 工具，一行命令搞定：
```bash
$ skill-installer <skill-name>
```
*(注：安装完后记得执行 `codex restart` 让元数据生效)*

**去哪找好用的 Skill？**

现在社区生态已经非常繁荣了，星哥给大家整理了几个“秘密基地”：

*   **TokRepo** (tokrepo.com)：500+ 技能，支持中文，社区投票排序，非常靠谱。
*   **OpenAI 官方目录** (github.com/openai/skills)：根正苗红，首选这里。
*   **Anthropic 官方仓库** (github.com/anthropics/skills)：SKILL.md 规范的参考实现，质量极高。

废话不多说，接下来进入正题，看看星哥私藏的 **几个必装 Skills** 到底神在哪里。为了方便大家对号入座，我把它们分成了四大实战场景。



## 场景一：谋定而后动，告别“无脑输出”

很多新手用 AI，上来就丢一句“帮我重构这个微服务”，然后 AI 就开始瞎写，写偏了你再改，Token 几万几万地烧。

### `create-plan`：先画图纸，再施工
```
# 官方安装
$ skill-installer install create-plan

# 或从LobeHub安装
# 访问 https://lobehub.com/skills 搜索 create-plan
```



星哥点评：这个 Skill 会**强制 Codex 在写任何代码前，先输出一份结构化的执行计划**（`<NAME>_PLAN.md`）。就像真实的架构师一样，先出设计方案，你评审点头了，它再开始敲代码。彻底根治“Prompt First 乱写”的顽疾，大幅减少返工。



### `Planning-with-Files`：给 AI 配个“外接大脑”

```
# 方法一：使用plugin marketplace（如果使用Claude Code，Codex同理映射到.agents/skills）
/plugin marketplace add OthmanAdi/planning-with-files
/plugin install planning-with-files@planning-with-files

# 方法二：手动安装
mkdir -p ~/.agents/skills/planning-with-files
curl -L -o skill.zip "https://mcp.directory/api/skills/download/593"
unzip -o skill.zip -d ~/.agents/skills/planning-with-files
rm skill.zip
```



*   **星哥点评**：任务链条太长，AI 聊到一半失忆了怎么办？这个 Skill 会把 Markdown 文件当成 AI 的**外挂记忆库**。它会自动创建 `task_plan.md`、`findings.md` 等文件记录进度和决策。哪怕你中途清空了上下文，它也能从文件里完美恢复状态，跨会话的大型重构必备！



## 场景二：质量保卫战，拒绝“屎山代码”

AI 写的代码往往“能跑，但全是坑”。怎么让 AI 像个严格的资深工程师一样干活？

### `Superpowers`：强迫 AI 搞 TDD（社区最火🔥）

```
# 创建Codex技能目录
mkdir -p ~/.agents/skills

# 克隆Skill到该目录下（以superpowers为例）
git clone https://github.com/obra/superpowers.git ~/.agents/skills/superpowers

# 如果使用Codex App，某些版本也可能需要同步到.codex/skills
mkdir -p ~/.codex/skills
cp -r ~/.agents/skills/superpowers ~/.codex/skills/
```



*   **星哥点评**：GitHub 90k+ 星的热度不是吹的。它的核心理念是**强制 TDD（测试驱动开发）+ 自动代码审查**。在写业务代码前，先逼着 AI 写测试用例；写完代码，主动执行 Review。这套“先测试、后实现、再检查”的组合拳，能帮你挡住 90% 的边界条件遗漏。

### `brooks-lint`：用 6 本神作教 AI 做人

```
# 方法一：直接克隆
git clone https://github.com/hyhmrright/brooks-lint.git ~/.agents/skills/brooks-lint

# 方法二：使用CLI安装
npx @bbhxwl/skills install brooks-lint --target codex
```



*   **星哥点评**：普通的 Lint 工具只查语法，这个 Skill 却从《人月神话》、《代码大全》、《整洁架构》等 6 本软件工程神作中提炼了审查维度。它能直接扫描你的 PR，从**概念完整性、架构边界、代码异味**等深度维度进行诊断，并给出修复指引。团队统一代码规范的利器。

### `pr-review`：7x24 小时无情的 Review 机器

```
$skill-installer install pr-review
```

*   **星哥点评**：直接挂载到 GitHub Actions 上。只要有人提 PR，它自动读取 diff，从功能正确性、安全漏洞、资源泄漏等多个维度进行扫描，最后把结构化的审查报告直接贴在 PR 评论里。团队 Code Review 的效率直接起飞。

## 场景三：运维与测试的救星

后端和 DevOps 兄弟们的福音来了，那些折磨人的脏活累活，交给 AI。

### `gh-fix-ci`：CI 报错排查，从 20 分钟压缩到几秒

```
# 官方安装
$skill-installer install gh-fix-ci

# 从LobeHub安装
# curl https://lobehub.com/skills/composiohq-awesome-codex-skills-gh-fix-ci/skill.md
# 然后按照提示完成安装配置

# 从Community Registry安装
npx @bbhxwl/skills install gh-fix-ci --target codex
```



*   **星哥点评**：GitHub Actions 红了？以前你得去翻几百行日志，现在这个 Skill 会自动读取失败记录，区分内外部错误，**直接定位问题根源并给出修复方案**。你只需要点个“批准”，它就能自动提交修复代码。

### `webapp-testing`：自然语言写自动化测试

```
$skill-installer install webapp-testing
```



*   **星哥点评**：基于 Playwright，你只需要用大白话描述“测试用户登录并加入购物车的流程”，它就能自动生成脚本、模拟点击、填表单，**最后还会给你附上测试截图和报错汇总**。而且它会自动学习你项目里现有的测试代码风格，绝不显得突兀。



## 场景四：全栈与架构的进阶利器

###  `frontend-skill`：拯救 AI 的“直男审美”

```
# 从官方Anthropic仓库安装
git clone https://github.com/anthropics/skills.git ~/.agents/skills/anthropic-skills
# 然后进入~/.agents/skills/anthropic-skills/skills/frontend-design 即可使用

# 或使用TokRepo一键安装
npx tokrepo install frontend-design
```



*   **星哥点评**：纯后端兄弟用 AI 写前端，最痛苦的就是生成的页面一股“复古 Bootstrap 味”。这个 Skill 把现代 UI 的设计规范（间距、色彩、阴影、动效）编码进了指令里，能引导 AI 做出极简、未来感等具有艺术感的页面，**颜值瞬间拉满**。

### `mcp-builder`：手搓 MCP Server 的脚手架

```
$ skill-installer install mcp-builder
```



*   **星哥点评**：MCP（模型上下文协议）现在有多火不用星哥多说了吧？这个 Skill 提供了一个“规划→实现→评估→优化”的四阶段向导，帮你构建符合最佳实践的 MCP Server，确保工具定义和错误处理都滴水不漏。

### `DocumentSkills`：让 AI 直接啃透需求文档

```
# 克隆官方仓库
git clone https://github.com/anthropics/skills.git ~/.agents/skills/anthropic-skills

# 然后在skills/document-skills目录下即可使用PDF、Word、Excel、PPT解析功能

# 或通过/plugin marketplace安装
/plugin marketplace add anthropics/skills/plugin
/plugin install document-skills@anthropic-agent-skills
```



*   **星哥点评**：支持在侧边栏直接打开 PDF、Word、Excel。当你需要让 AI 根据产品需求文档（PRD）或 API 说明书来写代码时，它能将非结构化的文档转化为 AI 可理解的数据，真正实现**文档驱动开发**。

###  `Context-Engineering`：AI 的“内存清理大师”

```
$skill-installer install context-engineering

```

*   **星哥点评**：AI 对自己 Token 快爆表这件事是“无知”的。这个 Skill 会在后台持续监控 Token 使用量，**快超时的时候，主动压缩非核心的上下文**，确保关键信息不被挤出窗口。长时间跑复杂任务的“防掉链子”神器。



## 建议

**别贪多，越“对”越好**：Skill 不是越多越好，堆砌 Skill 反而会增加系统的理解负担。建议先装 `create-plan` 和 `Superpowers` 体验一下，再根据痛点按需添加。

**Skill 是放大器，不是替代品**：Skill 的本质是“可执行的领域知识”。它不能替代你的架构思考，而是**放大你的思考效率**，帮你把那些繁琐的、容易出错的标准化流程自动化。

如果说 2024 年是 MCP 的“协议元年”，那 2026 年绝对是 Skills 的“应用爆发之年”。**用得好，AI 就能从“什么都能答的实习生”，秒变“什么都懂行的资深架构师”。**
