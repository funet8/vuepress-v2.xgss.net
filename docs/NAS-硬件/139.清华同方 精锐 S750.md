# 390块淘的清华同方小主机，改飞牛NAS：CPU够用，卡点在内存和供电



**导读：** 二手平台上，一台 2017 年的清华同方家用小主机，带 CPU、内存、固态盘，390 块能拿下。它能不能跑飞牛 NAS？能，而且比你想象中稳。



## 刷到的那台"准系统"

刷二手平台的时候，刷到一台小机器：清华同方精锐 S750，标价 390，写着"i3-7100T、8G 内存、120G 固态、原装无线网卡带蓝牙"。

第一反应是这价格不对劲。390 块，带 CPU 带内存带系统盘，比新出的迷你主机便宜一大截，不是矿渣，就是被拆得七零八落。

于是我去把这台机器的底细查了一遍。

结论先放这儿：**它不是什么矿渣，就是一台 2017 年家用办公小机器的正常二手价。**但有两个词得先掰扯清楚。

**第一，它其实不算"准系统"。**准系统的定义是只有机箱和主板，CPU、内存、硬盘全得自己配。这台机器是整套下来的，卖家这个说法不严谨。

**第二，390 块贵不贵，得看你算不算内存。**这台机器自带一根 8G DDR4，而 2026 年的 DDR4 行情，一根 8G 拆机条就要两百上下。把内存折算掉，机箱加主板加 CPU 加固态的实价，差不多三百出头。

这个价，值。

## 这颗 CPU 跑飞牛，够不够

先说飞牛。

飞牛 fnOS 是国产的 NAS 系统，基于 Debian 深度开发，**最大的特点是它不绑硬件**——只要是 x86_64 的机器，基本都能装。官方给的入门门槛很低：双核 x86_64、4GB 内存、16GB 系统盘。

拿这台机器对一下：

- **CPU**：i3-7100T 是 2 核 4 线程，基础频率 3.4GHz。注意它**没有睿频**，全核就一直跑 3.4GHz，不飙也不掉。对 NAS 这种"长期低负载、偶尔爆发"的活儿，反而稳。
- **功耗**：35W 的 TDP，平时待机十几瓦，满载也就六十瓦出头。一天电费两三毛钱。
- **核显**：HD 630。这条挺关键——**支持 H.264/H.265 硬编硬解，4K HEVC 10bit 的电影能直接硬解**，飞牛的海报墙和转码都吃得下。但它不支持 AV1，新格式片源只能软解，会很吃力。
- **内存**：原机 8G，这是短板，后面单独说。

一句话：**文件共享、挂下载、照片备份、影音刮削，这台机器完全不虚。**

但要同时跑好几个 Docker，再加 4K 转码，再加虚拟机，2 核 4 线程就开始喘了。

## 内存，别按去年的价算

这是我最想提醒的一条。

**2026 年的 DDR4，贵得不像话。**

年初 AI 把 DRAM 价格拉爆，一季度合约价环比涨了九成多，二季度还有六成，三季度才缓下来。传导到二手市场，现在一根 16G DDR4 拆机条的行价在 **400 到 470 之间**，牌子硬、成色好的还要往上走。今年暑期装机季，除了机箱外壳没涨，别的都在涨。

而这台机器上，只有一根 8G。

**我的建议是：补一根同规格的 8G 凑双通道，别直接上 16G×2。**

原因很简单。一根 8G 拆机条两百出头，两条凑成 16G，比买两根 16G 便宜一半还多；而且双通道对核显和 NAS 的数据吞吐都有好处，属于花小钱办对事。

有三个坑必须绕开：

- **别买带 ECC REG 的服务器条。**二手平台上最便宜那一档，很多是服务器内存（ECC REG）。**H110 这种桌面平台点不亮，插上去直接不认。**看到"REG""RDIMM"字样就跳过。
- **认频率。**这台机器跑 DDR4-2400 就够，2400 或 2666 的条子都能向下兼容，没必要为高频多花钱。
- **验金手指。**拆机条看金手指有没有氧化发黑，收到先跑一遍内存测试再用。

另外一句：这波涨价已经在收尾，**别囤条子**。

**16GB 是这台机器做 NAS 的底线。**你要跑 Docker、相册人脸识别、影片刮削，8G 是真不够，缓存一吃满，硬盘读写就被拖着走。



## 两个 SATA 口，供电只有一个

这条是我觉得最该提前知道的细节。

机器上有 **2 个 SATA 数据接口**，看起来能接两块硬盘，对吧？

问题在于 **SATA 电源插头只有一路**。而 3.5 寸机械盘每块都要独立供电，这就意味着：**原装状态下，你只能直接带一块 3.5 寸盘。**

解决起来不难——买一根 **"SATA 一分二"电源线**，用一个电源口分出两个头。几块钱的东西，是大家公认最省事的办法。

还有一句：**外置适配器别用杂牌。**这种小机器主板供电设计本来就精简，适配器一不稳，烧板子是小事，硬盘跟着一起挂才叫心疼。

## 盘位和机身厚度

记得那个尺寸吗，**92.5mm**。

这个厚度决定了一件事：**别指望它塞两块 3.5 寸盘。**原装机箱里能稳妥放下的，基本就是一块 3.5 寸盘，或者两块 2.5 寸。

想多上盘，只有两条路：

- **系统盘放板载 M.2，数据盘走外接**，机身保持原来那个薄样子；
- **把主板拆出来换大机箱**，但这样就不再是"390 块一台小机器"的故事了。

顺带提一句，官方资料里说机身上有 PCIe 扩展槽。但 9 厘米的厚度摆在这儿，真要插卡，基本只能选**半高（刀版）**的。想加阵列卡，先量尺寸再下单。

**还有一条比配置更重要的：单盘就是单点故障。**这台机器上我只敢放影视资源和临时文件。真正不能丢的东西，**本地一份、云端一份**才叫备份。云端那份我习惯丢对象存储，按量付费，一个月几块钱，比再买一块盘省心，也不占地方。



## 要不要升级 CPU

LGA1151 的 7 代平台，能换的 CPU 不少：i5-7400、i5-7500、i5-7600、i7-7700。

**但我不建议一上手就换。**

第一，**H110 芯片组对 CPU 的支持要看 BIOS**，有的型号得刷过最新 BIOS 才能认 7 代，买 CPU 之前先确认。

第二，**这机器散热和供电都是按 35W 设计的**。i5-7500 以上是 65W，塞进 9 厘米的薄机身，热量余量和供电余量都得打问号。

第三，**看你干什么。**只是文件共享加挂下载，i3-7100T 真够用。真到了要跑多容器、要转码、要多开虚拟机的程度——那也不是换个 CPU 能解决的，是整机定位该往上走了。

用它自带的 i3 撑到确实不够，再谈升级，这笔钱才花得值。

## 买之前，说几句实在的

**值得买的理由**：三百多块拿到一台带 CPU、带内存、带固态、带无线网卡的完整小机器，功耗低、体积小、能上飞牛，这个组合在今天的二手市场里不多见。

**要留个心眼的**：

1. **成色和拆机痕迹。**老机器被拆过的不少，看看螺丝有没有花、机箱有没有撬痕。
2. **无线卡和原装适配器在不在。**这两样是卖家常拿掉的东西，缺了要压价。
3. **硬盘托架。**有些卖家把原装托架抽走，后面加装机械盘会麻烦很多。
4. **价格区间。**带 CPU、内存、系统盘且成色好的机器，三四百是合理价；上到五百，就可以认真考虑加钱买 N100 平台的新机器了。

最后一句：**它是一台"够用的折腾机"，不是"省心的成品 NAS"。**不介意动手、图便宜、就想先跑个飞牛试试水，它很合适。想插上就用、不想碰任何命令行，还是买成品。



## 说到底

三百多块这个价位上，这台清华同方 S750 出乎我意料地均衡：低压 7 代 i3，功耗低得很，核显能硬解 4K HEVC，板载无线网卡能直接接路由器。

**真正制约你的不是 CPU，是内存价格、SATA 供电，还有那 9 厘米的机身厚度。**

这三件事想明白了再下手，它就是一台很称职的家庭轻 NAS。
