# 免费玩转Cloudflare-15：Cloudflare 免费档能白嫖到什么程度

导读：这篇讲的是 Cloudflare 免费档到底白送了多少东西。从 DNS、CDN 到数据库、对象存储、AI 推理，我逐个查了官方额度，顺手做了一张速查卡，也把两个真实的坑写清楚了。



## 先破一个误会：它不是"免费 30 天"

很多产品的"免费"，真实含义是"免费 30 天，到期自动扣款"。

你注册的时候绑了卡，忘了取消，第二个月账单就来了。

Cloudflare 的 Free 套餐不是这个路数，有两点区别很大：

**第一，没有到期日，注册也不要求绑卡。** 官网的注册入口上写着一句话，大意是"不需要信用卡"。我当年注册的时候确实一张卡都没填。这句话的实际意义是：**不存在"忘记取消被扣钱"这回事。**

**第二，额度按天清零，不是一次性体验包。** Workers 免费档的请求额度是**每天 10 万次**，UTC 零点重置。不是"总共给你 10 万次"，是每天早晨重新给你 10 万次。这个概念差别很大——个人项目一天 10 万次请求，早就不是小流量了。

还有一点，它跑的不是什么"免费用户专用降级集群"。Cloudflare 的网络铺在 **330 多个城市**，你用免费档，走的还是同一张网。



## DNS、CDN、证书、抗 D

你把域名服务器切到 Cloudflare，免费档立刻给你四样东西。

**权威 DNS**，全球 Anycast 解析，支持 DNSSEC，记录条数在免费档基本不构成限制。

**CDN 缓存，不限流量。** 这一项在按 GB 计费的云厂商那里，是最容易肉疼的开支。

**Universal SSL 证书**，自动签发、自动续期。你完全感觉不到它的存在——而单独去买一张通配符证书，一年几百块是要的。

**不限量的 DDoS 防护。** 官方用的词是 unmetered，攻击流量再大也不会另外给你开一张单子。

还有个常被忽略的：**免费档也带一套基础 WAF 托管规则**，OWASP 里那些常见的注入和恶意爬虫能拦一道，另外还能自己写 3 条 Page Rules、100MB 以内的请求体随便传。

对个人站点来说，这相当于白捡了一层保险。

## 开发者全家桶：¥0 预算跑一个全栈

真正让我觉得"这不太像一家上市公司干得出来的事"的部分，从这里开始。

前端、函数、数据库、对象存储，免费档各给一份，而且互相之间是原生打通的，不用你自己拿胶水拼。

### **Workers，是这套东西的心脏。** 

跑在边缘节点上的函数运行时，主打无冷启动。免费档每天 10 万次请求，单次请求 10ms CPU 时间、128MB 内存。个人 API、博客后端，绰绰有余。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791876482707.png?tx)

### **Pages 管静态站点。** 

Git 仓库推上去自动构建部署，每月 500 次构建，单个站点最多 20000 个文件，静态资源的请求带宽不限。个人博客、文档站、产品落地页，这一项就把选择题做完了。

### **R2** 

它兼容 S3 API，免费给 10GB 存储、每月 100 万次写类操作、1000 万次读类操作。

真正的杀招是**出口流量零费用**。AWS S3 把数据吐到公网大约收 0.09 美元每 GB，R2 这一项恒为零。放图床、放模型权重、放下载包，流量再大，也不用半夜起来看账单。

**D1 是 Serverless SQLite**，免费档每天 500 万行读、10 万行写，全账户共 5GB 存储。**KV 键值存储**每天 10 万次读、1000 次写，1GB 空间，放配置和缓存正合适。还有 **Hyperdrive**，免费档每天 10 万次查询，让 Workers 直连你放在别处的老数据库。



命令行大概就长这样（示意，不是官方文档原文）：

```bash
npm create cloudflare@latest my-app   # 生成 Workers + Pages 项目
npx wrangler deploy                   # 部署函数
npx wrangler r2 bucket create backups # 建 R2 桶
```

不想敲命令，网页控制台也能把它们全建起来。



## AI 推理也白送：每天 1 万 Neurons

这块是很多人不知道的。

**Workers AI** 把 GPU 推理做成了 Serverless，模型目录里有 50 多个，从 LLM、文生图到语音转文字都有。免费档每天给 **10000 Neurons**，这是它衡量推理算力的单位，第二天清零重给。

1 万 Neurons 能干什么？官方给过一组换算：大概 **100~200 次 LLM 问答、500 次翻译、500 秒语音转文字、1 万次文本分类**。

不过额度买到的算力，跟模型大小关系极大。最小的 llama-3.2-1b，每百万输入 token 只要 2457 Neurons，百万输出 18252；到了 70B 那一档，光是百万输出就要 20 万以上 Neurons。

所以结论很明确：**分类、摘要、向量化这类小模型日常活，免费额度相当宽裕；真要跑重推理，就得精打细算，或者上付费档**（超出部分 0.011 美元每千 Neurons）。

对"给我的 side project 加个 AI 功能"这个需求来说，够了。



## 最容易错过的福利

### **Cloudflare Tunnel** 

把家里 NAS、树莓派上的服务发到公网，不需要公网 IP，也不用在路由器上开端口——服务器主动向 Cloudflare 建一条反向连接。隧道本体免费，不限数量、不限流量，还能绑自己的域名。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791876668419.png?tx)

以前这类需求我都是用 ngrok 凑合，现在直接换成它了。

### **Zero Trust**

配套 Tunnel 用的零信任访问控制，免费档给 **50 个用户席位**。官方原话我印象很深，大意是"前 50 个员工算我们的"。五个人以下的团队，等于白拿一套企业级方案。

### Turnstile 

人机验证组件，验证码的替代品，大多数用户全程无感。免费档最多 20 个挂件、每个挂件配 10 个主机名，调用量不设限。

### **Email Routing** 

给自己的域名配自定义地址（比如 hi@你的域名），邮件直接转发到你常用的邮箱。免费，官方声明不存储邮件内容，还带钓鱼拦截。

### **Registrar** 

域名按注册局批发价卖，零加价，WHOIS 隐私保护免费，支持 **390 多个**顶级域名。GoDaddy 靠域名加价赚钱，Cloudflare 把域名当成生态入口——同一种生意，两套算法。

## 凭什么让你白用

白送的背面是生意。这套免费档的商业逻辑其实非常清楚，三步：

**第一步，入口。** 域名是开发者在互联网上的身份锚点。Registrar 按成本价卖、DNS 免费托管，你的整条基础设施链路从第一天起就默认长在它的生态里。

**第二步，成本已经被规模摊薄了。** 330 多个城市的节点本来就在那儿转着，多服务一个免费用户的边际成本，远低于按企业价卖给他的感知价值。

**第三步，等你长大。** 个人项目变成业务，请求量冲破免费额度，Workers 付费档 5 美元/月起，网站 Pro 档 20 美元/月起（按年付）。升级路径是平滑的，多数人也心甘情愿。

**免费档负责"轻"，自己的服务器负责"稳"**，这两件事不冲突。

R2 的零出口费还有另一层进攻意味。出口费是云厂商锁定客户的核心手段：数据进了我的网，搬走就要交路费。Cloudflare 把它直接归零，打的正是 AWS 定价体系里利润最厚、用户骂得最凶的那一块。

R2 定价页上挂的那个示例负载就是广告本身——同样一份数据加流量，S3 每月 868 美元，R2 每月 173 美元。



## 注意

夸完了，得说点不好听的。有两件事我建议你提前想清楚。

### 坑一：免费额度是硬切断，不是软限速

Workers 超过当天 10 万次，当天直接报错，不会给你降速慢慢跑。所以你必须在 **fail open（放行流量、跳过函数）** 和 **fail closed（直接显示错误页）** 之间做选择。

这个选择在安全场景里是真实的设计负担——放行意味着防护失效，拦下意味着业务中断。真上生产之前，先把这条逻辑想明白。

### 坑二：用得越爽，搬走越贵

函数、数据、域名解析都在同一张网里，生态便利的另一面就是迁移成本。这不是 Cloudflare 独有的问题，但它的免费档确实让人更难离开。

还有个细节：**免费额度的硬边界比看上去紧**。R2 10GB 是硬上限，做图床、做文件分享，很容易填满；KV 每天只有 1000 次写，拿它当 session 缓存或者计数器，一天就爆。D1 单个库上限 500MB，数据集再大就得考虑迁移了。

用之前先算一算自己的量级。
