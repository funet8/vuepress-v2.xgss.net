## 这个钱包，真不是给人类用的

**现在只能预约昵称（Handle），还不能充值、转账、付钱**



Cloudflare预约名字 ≠ 完整钱包功能；正式支付 / 充值功能尚未上线，上线后预约过名称的用户会收到通知。

因为未来的 AI Agent 肯定会占据互联网上的大部分区域，包括交易。



### 场景一：AI 购买服务

以后你只需要对 AI 说一句：“帮我把这段视频翻译成日语，并配上音。” 

AI 就会自己去网上找合适的翻译 API，自己比价，自己完成支付，最后把成品交给你。而不是像现在这样，还得你手动去配置 API、人工充值。



### 场景二：网站为 AI 提供服务

反过来，如果你是个开发者，只需要提供一个接口，AI 就能自动支付并调用。

你会发现，无论是 PayPal、Stripe 还是支付宝、微信，它们的设计初衷都是“人类”。

它们很难解决一个核心问题：**“一个 AI Agent 如何证明自己是自己？它到底能花多少钱？”**

于是，Cloudflare Wallet 就应运而生。它主打的就是 **Machine to Machine（机器对机器）** 的自动化交易。



## 现在就能抢注“靓号”
虽然完整的支付功能还没全面上线，但 Cloudflare 已经开放了 **“钱包 ID（Handle）”的认领预约**。

这就跟当年抢注域名一样，好名字先到先得！星哥强烈建议大家现在就去占个坑。

**👉 抢注地址：** `cloudflare.pay`

**⚠️ 抢注规则（必看）：**

1. 你需要有一个 Cloudflare 账号（免费的就行）。
2. **一个 CF 账号只能预约 1 个名字**，一旦锁定，不能随意修改或释放。
3. 格式是 `你的ID.cloudflare.pay`。
4. 短词、品牌词、高频靓号抢注速度极快，拼的就是手速。

## 未来上线后，它能干嘛？

等 Cloudflare Wallet 正式开放完整功能后，它的架构会非常清晰，分为两层：

### Account Wallet（主人主钱包）

这个由你（人类）来管理。

负责充值稳定币、提现，以及管控整体预算。

### Virtual Wallet（AI 虚拟子钱包）

这个是分配给你的 AI Agent 或 Worker 程序用的。

你可以给它设置**消费上限、允许支付的服务商白名单、单笔限额**。

AI 在限额内自动调用 API 付费，完全不需要人工确认。

**对于开发者来说：**

你可以直接在 Cloudflare Workers / Pages 里用官方 JS SDK，通过 API 控制子钱包的支出。配合他们之前推出的 Monetization Gateway（变现网关），AI 智能体的自动化交易闭环就彻底打通了。
