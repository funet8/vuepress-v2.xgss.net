# 玩转Cloudflare-18：AI做的网页一键部署网页，被 Cloudflare 压缩成了一次拖拽

导读：这篇讲 Cloudflare 7 月上线的免费小工具 Drop——不注册、不买服务器、不配环境，把文件夹往网页里一拖，几秒钟拿到一个公网地址。我拿它实测了一轮，把流程、坑和适合谁一次讲清楚。下次给客户演示网页就不用再求人了。

这个工具叫 **Cloudflare Drop**，它干的就一件事：**把"部署静态网页"这道工序，压缩成一次拖拽。**



## 以前 vs 现在，部署网页

先看以前。我让人写个网页，从成品到能在浏览器打开，一般要走这一串：

- 找台服务器或者托管平台，注册账号
- 创建项目、关联仓库
- 配构建命令，或者手动传文件
- 等 HTTPS 证书签发
- 再把地址发出去

每一步都不难，但**串起来就是半小时起步**。要是给客户看个 demos 页、给朋友预览个作品集，这半小时纯属浪费。

现在呢？打开 Drop，把文件夹拖进去，完事。得到的是：

**一个直接可访问的公网地址 + 一个 1 小时的"认领窗口"。**

地址是挂在 Cloudflare 全球网络上的，海外访问速度不用担心。

## 三分钟上手，流程就五步

实际用下来，完整流程长这样：

1. 准备好静态文件：HTML、CSS、JS、图片、字体，入口文件是 `index.html`
2. 打开 cloudflare.com/drop
3. 把**文件夹、ZIP 压缩包、甚至单个 HTML 文件**直接拖进去
4. 几秒后拿到一个 `workers.dev` 的公网地址
5. 满意，就点 Claim 认领到自己的 Cloudflare 账号；不满意，关掉页面，一小时后它自动消失

第 3 步里藏着一个很多人不知道的细节：**单个 .html 文件也能直接传**，任意文件名，Drop 会把它当首页来服务。你手里只有一页 AI 生成的 HTML？不用打压缩包，直接扔。

认领之后的站点就归你了，可以绑自己的域名、看性能监控、设私有访问，甚至允许 AI 以 Markdown 格式读取站点内容。不认领？也不用管，**1 小时后自动回收**，不留垃圾。

## 注意

有个小坑得说在前面。

实测发现，如果你的文件夹里混着 `.sh` 脚本、`.git` 目录、`.env` 这类文件，**拖进去会直接报错**，整个上传被拒。

解决办法很简单：上传前把目录清理一遍，只留 `.html`、`.css`、`.js`、图片、字体这些真正的静态资源。

顺手把密钥、配置文件这类敏感东西也剔掉——本来就不该出现在要公开的目录里。

另一个要记的数字：Claim 链接 **60 分钟过期**。它本质是临时账号的所有权凭证，谁拿到谁就能认领这个站，所以别顺手发到群里。
