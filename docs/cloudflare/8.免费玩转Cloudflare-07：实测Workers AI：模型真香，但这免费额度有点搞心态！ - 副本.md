## 二、实操：3步接入 Cherry Studio

### **第1步：获取“通行证”（API Token）**

1. 登录 Cloudflare 控制台。
2. 左侧菜单找 `构建 (Build)` -> `AI` -> `Workers AI`。
3. 点击 `REST API`，选择 `创建 Workers AI API 令牌`。
4. **注意：** 生成的 Token 只显示一次！赶紧复制保存下来。顺便把页面上的 `Account ID` 也抄下来。

### **第2步：在 Cherry Studio 里配置**

1. 打开 Cherry Studio，点左下角 `设置` -> `模型服务` -> `自定义服务商`。
2. 添加服务商，类型选 **OpenAI 兼容**。
3. 填入以下三剑客：
   - **API 地址**：`https://api.cloudflare.com/client/v4/accounts/{你的Account ID}/ai/v1`
   - **API Key**：刚才复制的 Token
   - **模型 ID**：比如 `@cf/moonshotai/kimi-k2.6` 或者 `@cf/deepseek-ai/deepseek-r1-distill-qwen-32b`

模型ID可以去这里找： https://developers.cloudflare.com/workers-ai/models/

📝 **文本大模型（卷王之王）**

## 五、横向大 PK：CF vs OpenRouter vs NVIDIA

为了让大家看得更直观，星哥拉了另外两个主流平台做个对比：

| 对比维度       | Cloudflare Workers AI  | OpenRouter       | NVIDIA build     |
| :------------- | :--------------------- | :--------------- | :--------------- |
| **模型数量**   | 80+                    | 300+ (最多)      | 50+              |
| **免费白嫖度** | ❌ 极抠 (每天10K神经元) | ✅ 较多真免费模型 | ✅ 有免费尝鲜额度 |
| **网络延迟**   | ✅ 极低 (全球边缘加速)  | ❌ 一般           | ❌ 一般           |
| **视频生成**   | ✅ 支持 (HappyHorse)    | ✅ 支持           | ❌ 不支持         |
| **计费方式**   | 神经元 (自定义)        | 按 Token         | 按 Token         |

**总结一下各家的脾气：**

- **OpenRouter / NVIDIA**：适合**白嫖党**和**尝鲜党**，免费模型多，但高峰期可能限速。
- **Workers AI**：适合**效率党**和**多模态玩家**，胜在速度快、生态好、有独家视频模型，但得掏钱。
