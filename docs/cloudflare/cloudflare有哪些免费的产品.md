# cloudflare有哪些免费的产品，普通人可以薅哪些羊毛

Cloudflare 的免费套餐（Free Tier）在互联网圈素有“业界良心”之称。对于普通人来说，它可以帮你**零成本建站、加速网站、做图床、远程访问家里设备、搭建域名邮箱**，甚至**免费练手全栈开发**。

以下是普通人最值得薅的羊毛，按实用程度排序：

---

### 1. DNS + CDN + SSL 安全加速（最基础，必用）
只要是个人博客、网站或任何 web 项目，这是必挂的“黄金三件套”。
*   **免费 DNS 解析**：解析速度极快，支持海外 Anycast，比很多域名注册商自带的 DNS 稳定。
*   **全球 CDN 加速**：静态资源（图片、JS、CSS）自动缓存到全球节点，海外访问速度肉眼可见提升。
*   **免费 SSL/TLS 证书**：自动颁发 HTTPS 证书（Universal SSL），一键开启强制 HTTPS，无需自己买证书或手动续期。
*   **基础 DDoS 防护**：免费抵御常见网络攻击。

**适合谁**：有域名、有网站的所有人。

---

### 2. Cloudflare Pages（免费静态网站托管）
相当于 GitHub Pages 或 Vercel 的竞品，但背靠 Cloudflare 的边缘网络。
*   **绑定 GitHub/GitLab**：提交代码后自动构建、自动部署。
*   **支持自定义域名 + HTTPS**：自动生成证书。
*   **预览链接**：每个 Pull Request 自动生成预览地址。
*   **构建次数**：每月 500 次构建额度过个人使用绰绰有余。

**适合谁**：个人博客（Hugo/Hexo/VuePress 等）、前端作品展示页、文档站点。

---

### 3. R2 对象存储（最“值钱”的羊毛）
Cloudflare 对标 AWS S3 的对象存储。
*   **巨羊毛：免出站流量费（Egress）**。这是它相比阿里云 OSS、AWS S3 最大的杀器。从 R2 流出到公网的下载流量**免费**。
*   **每月免费额度**：10 GB 存储 + 100 万次 A 类操作 + 1000 万次 B 类操作（读取）。
*   **可绑定自定义域名 + CDN**：可以当图床、软件分发站、备份盘、网盘前端存储。

**适合谁**：需要图床的个人博客主、需要分发文件的开发者、想备份资料的用户。

---

### 4. Cloudflare Workers（边缘计算 / 云函数）
在 Cloudflare 全球边缘节点上运行 JavaScript/Rust 代码。
*   **每天 10 万次免费请求**，对普通人完全够用。
*   **可用场景**：做 API 接口、聚合 RSS、短链接服务、网站导航、图片处理、反代请求等。
*   配合 R2 或 KV，可以搭出很多有趣的小工具。

**适合谁**：想写点轻后端但不想买服务器的开发者、想折腾小工具的极客。

---

### 5. Zero Trust Tunnel（免费内网穿透 / 反向代理）
这是普通人最容易忽略的**神器**。原名叫 `cloudflared`。
*   **功能**：把家里没有公网 IP 的 NAS、树莓派、Home Assistant、Windows 远程桌面等暴露到公网，通过自定义域名（如 `nas.yourdomain.com`）访问。
*   **优点**：自带 HTTPS、无需公网 IP、无需备案（你走 Cloudflare 的隧道）、**免费且不限流量**（合理使用下）。
*   **替代方案**：完全替代付费的 Ngrok、FRP 内网穿透。

**适合谁**：家里有 NAS、想外网访问 Home Assistant、想远程连接家里电脑的人。

---

### 6. Email Routing（免费域名邮箱转发）
*   **功能**：使用你自己的域名收邮件（如 `contact@yourname.com`、`github@yourname.com`），自动转发到你现有的 Gmail、QQ 邮箱或 Outlook。
*   **无限别名**：可以随便设置前缀，比如注册不同网站用不同别名，泄露了能直接看出是谁卖的。
*   **完全免费**，无需购买任何企业邮服务。

**适合谁**：已经买了个人域名、想玩逼格或管理邮件的普通人。

---

### 7. Turnstile（免费人机验证）
reCAPTCHA（谷歌验证码）的免费替代品，国内也能稳定加载。
*   **完全免费**，无请求量限制。
*   **隐私友好**，不需要用户点“我不是机器人”的公交红绿灯（通常是无感验证）。
*   集成到个人网站、博客评论区、登录页，防垃圾评论和机器人。

**适合谁**：有个人网站且被垃圾信息骚扰的站长。

---

### 8. Web Analytics（免费隐私友好统计）
*   **无需 Cookie 弹窗**：因为它不追踪个人身份，符合 GDPR 等隐私法规。
*   **完全免费**，添加一段 JS 即可看到访客来源、页面浏览量、核心网页指标等。
*   作为 Google Analytics 的替代品，数据足够个人使用。

**适合谁**：不想用百度统计/谷歌分析，或者嫌 Cookie 同意弹窗烦人的站长。

---

### 9. 1.1.1.1 / WARP（免费网络工具）
*   **1.1.1.1**：公共 DNS 解析器，主打隐私（不记录查询日志）和速度。
*   **WARP App**：免费版的 VPN-like 工具，主要加密你的 DNS 查询、保护公共 WiFi 安全，并在部分地区有网络线路优化效果（**注意：它不是翻墙工具，不保证能访问特定网络**，但作为隐私保护和网络加速工具是免费的）。

适合谁：所有手机/电脑用户，可免费下载 App 使用。

---

### 10. Registrar（成本价域名注册）
*   Cloudflare 卖域名几乎没有加价，是**成本价**出售（比如 .com 域名接近批发价）。
*   **坑点**：必须同时使用 Cloudflare 的 DNS，且转出/部分功能有限制。适合买了就不用挪窝的域名。

---

### 普通人“最佳薅羊毛”实战组合

| 你的需求                | 推荐组合                                                   | 每月花费 |
| :---------------------- | :--------------------------------------------------------- | :------- |
| **搭建个人博客**        | Pages + DNS + CDN + Web Analytics                          | ¥0       |
| **免费图床/网盘**       | R2（存储）+ CDN（加速）+ 可选 Workers（做上传前端）        | ¥0       |
| **远程访问家里 NAS/HA** | Zero Trust Tunnel + 自定义域名                             | ¥0       |
| **全栈开发练手**        | Pages（前端）+ Workers（API）+ D1/KV（数据库）+ R2（文件） | ¥0       |
| **个性化域名邮箱**      | Email Routing + 任意域名                                   | ¥0       |

### 注意事项（避坑）
1.  **Workers/R2 等可能需要绑卡**：激活 Workers 或 R2 时，Cloudflare 可能要求绑定信用卡/PayPal（只是验证，免费额度内不扣费），而 Pages 和 DNS 通常不需要。
2.  **国内访问玄学**：Cloudflare 的免费 CDN 国内没有节点（部分运营商有合约缓存但体验不一），国内访客访问可能不如又拍云/腾讯云 CDN 快，甚至被间歇性干扰。建议面向海外访客或学习用途。
3.  **免费额度够用但有限**：比如 Workers 每天 10 万次请求，超过后会停掉，对于个人项目足够，别拿去做大规模商业服务。

**一句话总结**：如果你有一个域名，Cloudflare 的 **DNS + Pages + R2 + Tunnel + Email Routing** 组合拳，几乎可以帮你零成本搭建一套完整的个人互联网服务生态。
