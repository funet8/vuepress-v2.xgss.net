# Windows 11 26H2 正式推送，24H2 用户该续命了，174KB 就能升个大版本



**导读：** 微软刚把 Windows 11 26H2 全量推了出来，安装包只有 174KB，重启一次就完事。但这事真正值得看的地方不是新功能，而是 24H2 家庭版/专业版 **10 月 13 日就停更了**——不升，等于以后没人给你打安全补丁。这篇把 26H2 到底送了什么、你要不要升、怎么升，一次说清，读完大概 8 分钟。

## 我第一眼以为数字写错了

我手上机器有点杂，NUC、小主机、云上的 Windows Server 都有。每次系统要跨大版本，我都习惯先摸清情况再动手。

所以这次看到 Windows 11 26H2 的安装包体积，我是真愣了一下。

**174KB。**不是 GB，是 KB。一个系统大版本更新，包体比我随手拍的封面图还小。

这次的 KB 编号是 **KB5121794**，微软 9 月 29 日面向全量用户开放。装完之后，系统版本号会从 24H2 / 25H2 变成 26H2，内部版本号是 **Build 26300.9550**。

下载几乎是瞬间完成，重启一次，2～5 分钟结束。硬盘不见少，等待时间基本感觉不到。

这套玩法其实 25H2 那会儿就见过一次，当时也觉得新鲜。现在 26H2 又来一遍，说明微软打算把这条路一直走下去。

那问题就来了——**一个 174KB 的东西，凭什么算一次大版本更新？**

## 因为功能早就躺你硬盘里了

说白了就两个字：**预埋**。

过去一整年的月度更新里，微软已经把新功能一块块塞进你系统盘了。只是塞进去的时候默认锁着，你看不见、也点不到。

26H2 这个启用包干的活，就是**把锁一个个拧开**。

微软官方的原话是这样：

> "An enablement package is a lightweight update that activates new features already included in the operating system through previous monthly servicing updates."

**启用包只负责激活那些已经通过月度更新进到你系统里的功能。**

它之所以能这么玩，是因为 24H2、25H2、26H2 三个版本**共用同一个服务分支**（代号 Germanium），底层平台是同一套。对一直保持更新的机器来说，从 24H2 跳到 26H2，实际工作量跟装个月度补丁差不太多。

还有一点得摆明白：**26H2 本身没有独占的新功能。**

它的价值就两件事：

1. 把过去一年陆续预置的功能**解锁**
2. 把系统支持周期**重置**（这才是重头戏，后面单独说）



## 26H2的点亮

功能清单不短，我挑日常真能用上的说。

### 1.任务栏终于能挪位置了

这是被喊了好多年的东西。

以前任务栏只能钉死在屏幕底部。现在**上下左右四个方向都能放**，放顶部的时候，开始菜单和搜索框会从顶部往下展开，不别扭。

还多了一组「**任务栏大小**」设置，分「默认」和「紧凑」两档，而且把「任务栏大小」和「应用图标大小」拆成了两个独立选项——想只缩图标、不动任务栏高度，现在可以了。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791599163703.png?tx)



### 2.开始菜单：三个区域能单独开关

固定项目、最近项目、所有应用，现在能**各自独立显示或隐藏**。

那块一直被吐槽的「推荐」，改名叫「**最近使用**」了。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791599245001.png?tx)



### 3.搜索变聪明了不少

Windows Search 加了**错别字识别**和**应用简称匹配**。

外媒 Windows Latest 的实测挺有说服力：

输入 `pwerp`，能匹配到本地的 PowerPoint；

输入 `tskm`——既漏字母又多字母——照样匹配到任务管理器，还会顺手给你「打开 / 以管理员身份运行 / 固定到任务栏」几个选项。

这个改动的实际收益比我预想的大。以前找应用基本靠记全名，记不清就只能翻开始菜单。

另外它内置了**关掉网页搜索结果的开关**，想让搜索只翻本地内容，现在能关干净。常用文件夹也支持自动索引，结果分类更清楚。



### 4.文件资源管理器：解压党有福

新增支持一批压缩包格式：**uu、cpio、xar、nupkg**。

`nupkg` 是 NuGet 的包格式。以前为了解一个它得单独装工具，现在系统自带，这种小事省下来就是舒服。

其他还有：AI 操作图片、给 OneDrive / SharePoint 文档生成摘要、Home 页面记住各区域的展开折叠状态、云文件缩略图更可靠。工作和学校账户在主页多了「打开文件位置」和「询问 Copilot」。



### 5.任务管理器能看见 NPU 了

带 NPU 的机器，现在能在任务管理器里直接看 AI 算力占用。

「进程」「用户」「详细信息」三页都能调出 **NPU** 和 **NPU 引擎**列；「详细信息」页还有 NPU 专用内存和共享内存两列。集成在显卡里的神经引擎，会出现在「性能」页。

这个改动对判断"到底谁在干活"很有用。以前跑个本地模型，你只能盯着 CPU 和显卡猜。



### 6.安全性

这大概是 26H2 里最不显眼、但最实在的一部分：

- **管理员保护**：管理任务改用实时权限（just-in-time privileges）执行，而不是一直挂着一身管理员权限。提权攻击的门槛被抬高了。默认关闭，要用得靠 Intune 或组策略打开。
- **Sysmon 内置**：以前要单独下载的 Sysmon 系统监视器，现在直接进系统了，支持自定义配置和威胁检测，事件写进 Windows 事件日志。默认关闭，管理员手动开。
- **后量子密码学**：新增 **ML-KEM** 和 **ML-DSA** 支持。这事听着挺远，但"先把你加密数据收走、等量子计算机成熟了再解"这种路子已经在被讨论了。现在开始铺，不算早。
- **驱动信任收紧**：交叉签名驱动不再被默认信任。
- **Smart App Control** 现在**不重装系统**也能开关。
- **增强登录安全**：桌面 PC 和 Copilot+ PC 上，兼容的第三方指纹传感器也能用了。

无障碍那边也动了：放大镜的缩放和屏幕色调滤镜更细了，讲述人加了盲文查看器（Braille Viewer），语音访问在 Copilot+ PC 上扩展了自然语言指令和语音隔离。



### 7.其他项目

- **Emoji 17.0** 新表情（distorted face、fight cloud、hairy creature 这些）
- **Windows 设置备份默认启用**（备份系统设置 + Microsoft Store 应用列表）
- 蓝牙 LE 音频改进
- 桌面背景支持 DIB 图片
- 多桌面幻灯片壁纸

### 8.WMIC 没了

普通用户没感觉，但搞运维、写过 PowerShell 脚本的兄弟会有实感——**WMIC 在 26H2 被彻底移除了**。

还在脚本里用 `wmic` 的，建议现在就换掉：

```
Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3"
```



早改早省事。

别等某天跑自动化任务时，脚本突然报一句"不是内部或外部命令"。



## 要不要升级

我按手头遇到的几种情况整理了一下：

| 当前系统                  | 建议            | 理由                                |
| ------------------------- | --------------- | ----------------------------------- |
| Win11 24H2                | **立刻升**      | 家庭版/专业版马上停更，不升等于裸奔 |
| Win11 25H2                | 建议升          | 174KB 换两年支持期，成本几乎为零    |
| Win11 23H2 及更早 / Win10 | 走 ISO 全新安装 | 拿不到启用包，只能完整升级          |

另外还有个好消息：社区里有人反馈，从 25H2 升到 26H2 之后**内存占用降了大概 1.5～2GB**。老机器升级反而可能更顺一点，这点比预期好。

另一个提醒：**26H1 不会升到 26H2**。今年年初微软给部分新硬件预装的 26H1 是独立分支，别在那台机器上干等推送。



## 升级前，准备

### 一、备份这件事，别省

官方说这是"低打扰、低风险"的更新。但任何碰系统分区的操作，我还是建议先备份。

我自己的习惯是两层：

- **本地一份**：系统盘做快照或镜像；嫌麻烦至少把桌面、文档、下载三个目录挪到别的盘
- **异地一份**：真正不能丢的东西——合同、照片、代码、设计稿——别只躺在这一台机器里



### 二、三个已知 Bug

微软确认 26H2 至少有这三个已知问题：

- **USB 音频设备失灵**
- **企业域登录失败**
- **Azure 虚拟桌面黑屏**

关键在后面这半句：微软明确说明，**这些问题在 24H2 和 25H2 上同样存在。**

也就是说，这不是升级带来的新毛病，而是**老问题，不升也躲不过**。拿它当理由留在老版本，等于用更旧的系统承受同一批 Bug，还得额外赔上支持周期。

普通家用机基本碰不到，真踩了 USB 音频那个，把默认音频驱动切回去一般能绕开。



### 三、推送分批，搜不到别急

这轮微软走的是**受控分批推送**，先给兼容性评估最好的那批机器。你要是暂时没在 Windows 更新里看到 26H2，等几周是正常的。碰上安全保留（safeguard hold）的机器，会更晚。



## 怎么升：两条路

### 方法一：Windows Update（24H2 / 25H2 用户）

打开 **设置 → Windows 更新**，先把「**在最新更新可用后立即获取**」这个开关打开，然后点检查更新。系统校验完硬件条件，就会把 26H2 启用包推给你，下载完按提示重启就行。

这条路径基本不用你动手，也是我最推荐的。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791599475100.png?tx)



### 方法二：ISO 全新安装（23H2 / Win10 用户）

当前还在 23H2 甚至更早的，走不了启用包——**23H2 拿到的是一次约 6.5GB 的完整升级**。想要最干净的结果，直接下 26H2 的 ISO 全新安装更省心，微软官网已经放出 x64 和 Arm64 的正式版镜像。

动手前把这几点准备好：

1. 备份重要数据（再念一遍）
2. 网卡驱动先下好放 U 盘，不然装完可能上不了网
3. 原来绑定微软账号的数字许可证，装完登账号会自动激活
4. 装完先跑一遍 Windows 更新，把驱动和补丁补齐

## Windows 11支持周期

功能那些都是添头。**26H2 最大的价值，是它把你系统支持周期那张表扒了，重新发你一张新的。**

微软的现代生命周期策略下，Win11 家庭版/专业版每个大版本从发布起有 **24 个月**支持，企业版/教育版是 **36 个月**。

看这张表就清楚了（数据来自微软官方 Windows 11 版本信息页）：

| 版本     | 推出日期   | 家庭版/专业版终止 | 企业版/教育版终止 |
| -------- | ---------- | ----------------- | ----------------- |
| **26H2** | 2026-09-29 | **2028-10-10**    | **2029-10-09**    |
| 25H2     | 2025-09-30 | 2027-10-12        | 2028-10-10        |
| 24H2     | 2024-10-01 | **2026-10-13**    | 2027-10-12        |
| 23H2     | 2023-10-31 | 已终止            | 2026-11-10        |

盯住 **24H2 那一行**：家庭版和专业版，**2026 年 10 月 13 日终止更新**。

"终止更新"是什么概念？我列一下就不再收到了：

- 每月的安全更新和预览更新
- 已知问题修复
- 时区更新
- 技术支持

翻译一下：**你机器上的漏洞，从这个日子起没人给你补了。**

而升到 26H2，支持期直接跳到 2028 年 10 月。**用 174KB，换两年安全更新**——这笔账怎么算都不亏。





## 最后

这次 26H2 挺有意思——它几乎把"大版本更新"这四个字的含义改了。

**没有几 G 的下载，没有漫长的等待，一个 174KB 的开关，顺手把未来两年的安全更新也补齐了。**

对 24H2 用户来说，这不是"要不要尝鲜"的问题，是"要不要继续收到补丁"的问题。离停更没几天了，别拖。

对 25H2 用户来说，174KB 换两年支持期，投入产出比高得离谱，真没什么好犹豫的。
