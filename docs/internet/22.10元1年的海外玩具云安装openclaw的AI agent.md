## 10 元年付玩具云专属优化（解决 512M 低内存崩溃）

**关闭日志持久化**

```
openclaw config set logger.disk false
```

1. **限制单 Agent 上下文长度**：面板内设置 max_tokens≤1024；
2. **禁用沙箱代码执行**：`openclaw config set sandbox.enable false`；
3. 定期释放内存定时任务：

```
# 每天凌晨2点释放缓存
echo "0 2 * * * sync; echo 3 > /proc/sys/vm/drop_caches" | crontab -
```

## 常见报错 & 避坑

1. OOM 内存被杀

   现象：启动几秒自动退出；解决：升级机器至 1G 内存，关闭沙箱、日志磁盘存储。

2. 面板无法访问

   检查：防火墙放行 19890、启动命令带

   ```
   --host 0.0.0.0
   ```

   （允许外网访问）。
