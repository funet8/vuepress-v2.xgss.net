## 保姆级上车教程

废话不多说，直接上实操步骤，跟着星哥一步步来。

### 第一步：注册账号
老规矩，直达传送门：[Filebase 官网 pricing 页面](https://filebase.com/pricing/)。

进去之后直接注册，填个邮箱，收个验证码就搞定了。没有那些乱七八糟的绑卡套路，非常丝滑。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785303638358.png?tx)

### 第二步：创建存储桶（Bucket）
登录后进入主页，在左侧菜单找到 **Buckets**，点击 **New Bucket** 新建一个桶。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785303715176.png?tx)

**星哥避坑提示**：
这里的桶名字（Bucket Name）是全局唯一的。如果你随便起个 `test` 或者 `mydata`，绝对会提示被占用。建议命名稍微复杂点，比如加上年份或随机码 `xingge-backup-202607`，基本一次过！

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785303745695.png?tx)

### 第三步：上传文件与获取密钥
桶建好后，你就可以往里面传文件了。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785303850177.png?tx)

但这里要注意一个限制：**免费版是不支持公开访问的**（想搞公开图床直接外链的兄弟，得升级付费版了）。免费版的桶都是私有的，必须通过 S3 API 配合密钥来访问。

**怎么拿密钥？**

回到主页，找到 **Access Keys** 选项。

点击生成，把 **Access token** 和 **Secret key** 复制下来，妥善保存在你的密码管理器里。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785303885340.png?tx)



### 第四步：代码接入
拿到密钥后，就可以在你的项目里通过 S3 协议接入啦。星哥给大家整理了核心配置参数，直接抄作业：

```javascript
endpoint: 'https://s3.filebase.io',
accessKeyId: '你的_FILEBASE_ACCESS_TOKEN',
secretAccessKey: '你的_FILEBASE_SECRET_KEY',
region: 'auto',
signatureVersion: 'v4'
```
*（注：把上面的 `YOUR_FILEBASE_KEY` 等占位符换成你自己的密钥就行）*
