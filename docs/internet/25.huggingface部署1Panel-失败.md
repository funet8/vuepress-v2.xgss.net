## 部署步骤，手把手来

### 第一步：登录 Hugging Face

打开 huggingface.co，点右上角 **Log In**。没有账号就点 **Sign Up** 注册一个，填个邮箱设个密码的事，很快。

### 第二步：新建一个 Space

登录后，点 **New > Space**，进入创建页面。

这里有几个关键项要填：

- **Space name**：随便起个名字，比如 `my1panel`
- **Short description**：可填可不填，跳过
- **模板**：选 **Docker**
- **Docker template**：默认就是 **Blank**，不用动
- **Space hardware**：默认免费档，不用动
- **可见性**：默认 **Public**，保持公开才能公网访问



填完点底部的 **Create Space**，等几秒钟，Space 就建好了。

### 第三步：改 README，加端口

进入 Space 工作台后，点 **Files**，找到 `README.md`，点进去再点 **edit**，把内容换成下面这段：

```yaml
---
title: 1Panel运维管理面板
emoji: 💻
colorFrom: red
colorTo: gray
sdk: docker
app_port: 10086
pinned: false
---
```

**重点就是 `app_port: 10086` 这一行**，它告诉 Hugging Face，我们的应用跑在 10086 端口上。改完下拉，点 **Commit changes to main** 提交。

### 第四步：新建 Dockerfile

回到 Files 页面，点 **Contribute > Create a new file**，文件名填 `Dockerfile`，内容输入：

```dockerfile
FROM moelin/1panel:latest
EXPOSE 10086
```

然后点 **Commit new file to main** 提交。

到这里，配置部分就全部结束了。剩下的交给 Hugging Face 自己折腾。

### 第五步：等它构建完

提交之后，Space 会自动开始构建部署。点 **Log** 能实时看日志。状态会经历三个阶段：

- **Building**：拉取镜像，如果这一步报错，多半是镜像有问题或者 Dockerfile 格式写错了
- **Starting**：开始安装部署镜像
- **Running**：部署完成，可以访问了

看到变成 **Running**，就说明面板已经在跑了。

## 访问面板，注意这个坑

面板地址是：

```
https://[你的用户名]-1panel.hf.space/
```

等等，先别急着打开。1Panel 默认是**开启安全入口**的，正常本地部署可以用 `1pctl user-info` 命令查看入口。但我们现在是在 Hugging Face Space 里，进不去容器，命令自然也用不了。

那怎么办？

**敲黑板，这是本文最值钱的部分。** 我们用的这个镜像 `moelin/1panel:latest`，它的默认信息是固定的：

| 项目     | 默认值            |
| -------- | ----------------- |
| 端口     | `10086`           |
| 账户     | `1panel`          |
| 密码     | `1panel_password` |
| 安全入口 | `entrance`        |

所以真正的访问地址是：

```
https://[你的用户名]-1panel.hf.space/entrance
```

用上面这套账号密码登录，就能进 1Panel 的面板了。进去之后还能选语种，选中文就行。

---

## 登录后的第一件事

**别急着玩，先把安全三件套改了！** 毕竟默认密码全网都知道，公网又开着，不改等于裸奔。

进面板后，按这个路径改：

1. **改账号密码**：面板设置 → 面板 → 面板用户、面板密码
2. **改安全入口**：面板设置 → 安全 → 安全入口

两个都改掉，尤其是密码，设个复杂点的。改完再放心折腾。
