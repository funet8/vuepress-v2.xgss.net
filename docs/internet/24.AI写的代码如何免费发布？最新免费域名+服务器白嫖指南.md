# 一、 域名篇：给你的网站起个“门牌号”

域名是建站的第一步。

现在想免费搞个顶级域名不容易。

## 1. 真·免费顶级域名（重点推荐）

### dnshe

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1787563466593.png?tx)

###  us.kg

每人可以注册3个，完美支持接入 Cloudflare。颜值高、好记，白嫖党首选。

### pp.ua

乌克兰老牌

可以免费续期10年，非常良心。但注册门槛稍高，需要填写真实的乌克兰地址和手机号，适合有耐心的老手。

### Freenom

 tk / .ml / .ga / .cf / .gq

曾经的神，现在注册依然简单。

但**注意**：Freenom 现在的续费规则和回收机制很迷，随时可能被找回，**千万别放重要业务**。



## 2. 永久免费二级域名（老牌稳健）

### eu.org

欧洲老牌免费域名，逼格很高。缺点是审核极其随缘，等上几个月是常态。

### nom.za

南非域名，每人限注册1个，相对冷门但稳定。



## 3. 大厂“首年免费”域名（适合过渡）

如果你不想折腾小众后缀，可以薅一下国内大厂的羊毛，通常首年只要1块钱甚至免费：
*   ☁️ **腾讯云**：首年1元，`.cloud`、`.online`、`.icu` 等后缀任选。
*   ☁️ **OVHcloud**：买他家的主机套餐，送27种后缀域名首年免费（包含 `.com`、`.org` 这种硬通货）。



## 4. 平台自带子域名（最省事）

如果你只是写个静态博客或前端项目，直接用大厂的子域名最香：
*   **GitHub Pages** (`github.io`)：静态网站老大哥。
*   **Cloudflare Pages** (`pages.dev`)：访问速度起飞。
*   **Vercel** (`vercel.app`)：前端开发者最爱。
*   **Netlify** (`netlify.app`)：一键部署，傻瓜式操作。

# 四、 避坑指南



最后，星哥得给大家泼点冷水。白嫖虽爽，但有几个坑千万别踩：

1.  **数据无价，一定要备份！** 免费服务随时可能因为政策、资金问题停止运营（参考以前的 Freenom）。**千万不要把核心业务和重要数据放在免费资源上！** 定期备份到本地或对象存储是基本素养。
2.  **认清适用场景**：这些资源最适合用来做**个人博客、作品集、开源项目文档、开发测试环境**。如果是做商业项目，请老老实实买付费服务。
3.  **注意功能限制**：免费通常意味着限制带宽、存储或 CPU 峰值。用之前仔细看看服务条款（TOS），别因为违规被封号。
4.  **留好升级后路**：选择那些提供平滑升级到付费方案的服务商，以后项目做大了，迁移起来不费劲。
