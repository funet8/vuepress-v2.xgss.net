# 写完文章还要折腾排版？这个工具我后悔没早点发现



每次在本地用 Markdown 把文章敲完，那种"终于写完了"的轻松感，大概只能持续三秒钟。

因为接下来，你要把它发到公众号。

标题字号不对，代码块变成一坨纯文本，图片要一张张重新上传，外链直接吞掉……我上次光是调一篇技术文章的公众号排版，就花了快四十分钟。

四十分钟啊，够我再写八百字了。

后来一个做独立开发的朋友丢给我一个工具，用完之后我沉默了——原来这事儿，真的可以三秒搞定。

## 它叫文颜，干的事儿很简单

一句话概括：**把 Markdown 一键转成公众号、知乎、头条等平台能直接用的格式。**

不用打开网页，不用装浏览器插件，桌面端离线就能跑。

它的诞生背景也挺真实——作者自己用 Hugo 搭博客，文章写完之后想同步到公众号和知乎，结果每个平台都得单独折腾一遍格式。搞了几次之后他烦了，干脆自己写一个。

所以这工具不是那种"什么都能做但什么都不精"的大而全产品，它就解决一个事儿：**跨平台发文的排版适配。**

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1786612450853.png?tx)

## 几个"真香"的功能

### **1.代码高亮，终于不是纯文本了**

写技术文章的都懂，Markdown 里三个反引号包起来的代码块，到了公众号后台直接变白底黑字，看着跟记事本似的。文颜转换之后，代码块带语法高亮，跟你在博客上看到的效果一模一样。

### **2.外链自动转脚注**

公众号不支持外部链接，这个老问题了。文颜的做法是把正文里的所有外链自动提取出来，以脚注的形式放在文章末尾。读者能看到出处，平台也不报错，两全其美。

### **3.数学公式直接渲染**

写学术内容、算法分析的朋友，MathJax 公式在公众号里基本是灾难。文颜对公式的支持很完整，复杂的多行推导也能正常显示。

### **4.Mermaid 图表也能画**

流程图、时序图、类图……只要你在 Markdown 里用 Mermaid 语法写的，转出来就是渲染好的图，不用再手动截图贴进去。



![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1786612362820.png?tx)

## 主题这块，选择还挺多

内置了七八套 Typora 风格的主题，Orange Heart、Rainbow、Lapis、Pie 这些都有。

不满意的话也能自己改 CSS，或者导入第三方主题。我试了几个，默认那套就挺干净的，不用折腾。

另外它还支持导出长图，偶尔想在朋友圈或者社群里分享个截图，直接导出就行，不用再开截图工具拼半天。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1786612267976.png?tx)

## 不止一个版本，按需选择

这点我觉得挺贴心的：

- **macOS 用户** → App Store 直接下载，原生体验
- **Windows / Linux** → 跨平台桌面版
- **搞自动化的** → CLI 命令行版本，丢到 CI/CD 流水线里批量处理
- **想玩花的** → MCP 版本，接入 AI Agent 实现全自动发文

最后这个 MCP 版本多说两句。它基于模型上下文协议，理论上你可以让 AI 帮你完成"写稿 → 排版 → 传图 → 发草稿箱"的全流程。我还没深度折腾这块，但思路确实挺野的。

## 跟同类工具比，它强在哪

市面上做 Markdown 转公众号的工具不是没有，但大部分是网页版，依赖网络，功能也参差不齐。

文颜的几个点比较突出：

- 离线可用，不担心哪天网站挂了
- 平台覆盖广，公众号、知乎、头条、掘金、CSDN、Medium 都支持
- 代码高亮 + 公式 + Mermaid 三件套齐全
- 完全开源免费，Apache-2.0 协议，GitHub 上能看到源码
- 社区还在活跃维护，不是那种烂尾项目



## 什么人适合用

**只要你用 Markdown 写东西，并且要发到不止一个平台**，这工具就能帮你省时间。

技术博主、科研党、新媒体运营、内容团队……都适用。

它不会帮你写文章，但它能让你把"写完之后那些破事"的时间压缩到接近零。
