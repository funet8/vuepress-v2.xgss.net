# 一个开源 APK，让旧的安卓手机or平板直接跑 CarPlay

导读：这篇讲的是怎么不花钱把 CarPlay 弄进车机。一个建仓 19 天就冲到 1 万 Star 的开源 APK，装在车机上就能用，不用盒子、不用越狱、不用额外买硬件。我把它的真实数据、能干什么、装之前必须对号入座的门槛，还有三个我建议你提前想清楚的坑，都捋了一遍。



车机上的 CarPlay 这事，本质就是"原厂不给，那你自己掏钱"。

国内在售的比亚迪车型，绝大多数车机里压根没有 CarPlay。想用只有两条路：买个 CarPlay 盒子插在 USB 上，或者上第三方外挂方案。

盒子这条路的行情我不多说了，一百多起步，稳一点的三四百，还得跟断连、延迟、方向盘按键失灵这些毛病长期共处。

结果这两天，冒出个开源项目把这条路给抄了。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791881389976.png?tx)

**DiPlay。** 一个 Android APK，装在你的车机上，你的车机就变成了 CarPlay 的接收端。

GitHub：https://github.com/shihabal3amri/DiPlay

它不是官方方案，作者自己也只敢叫它"公开预览版"，后面我会专门用一段讲它随时可能失效的原因。但这不影响我先把它值得看的地方讲清楚。

我也是看了老张的视频，决定写这篇文章。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791878725959.png?tx)

## DiPlay不是盒子，也不是刷机

我把 DiPlay 的定位用一句话概括：**它是装在车机上的一个 CarPlay 接收端。**

理解了这点，下面这些"不需要"就顺理成章了：

- 不需要 iPhone 越狱，也不用装什么描述文件。
- 不需要买 CarPlay 盒子。
- 不需要 Mac，不需要账号，也不需要连远程认证服务器——认证是在本地完成的。
- 不需要 Root。核心的有线、无线连接也不需要 ADB。

它跟那些"刷机改车机系统"的路子完全不是一回事。你的原车系统还在，DiPlay 只是额外装进去的一个 App。

包名 `com.shihab.diplay`，可以和作者另一个项目 DiAuto 同时装着，只是同一时间只能跑一个投屏应用。

出身也挺清楚：底层基于开源项目 xcertplay（GPL-3.0），界面和网站沿用了作者自己的 DiAuto（AGPL-3.0）。不是什么来路不明的野包。



## 能怎么连、连上能干什么

连接方式官方给了四条，我按好上手的顺序排：

| 连接方式                    | 大致怎么弄                                                   |
| --------------------------- | ------------------------------------------------------------ |
| **USB 有线**                | 插数据线，车机上选"用 USB 连接"，手机点信任、允许本地 VPN    |
| **车机内置热点**            | 车机开热点（有 5GHz 优先用 5GHz），把热点名和密码填进 DiPlay |
| **Wi-Fi Direct**            | 车机和手机直连，不经过路由器                                 |
| **现有 Wi-Fi / 同一局域网** | 车机和 iPhone 各自连同一个路由器                             |

连上之后能干的活：

- **导航、音乐、通话、Siri**，跟插线 CarPlay 是一个界面逻辑，用你 iPhone 的那套 App。
- **同步到 HUD / 仪表**。在已验证的比亚迪固件上，导航的转向箭头、距离和街道名能显示到 HUD 或仪表区。作者的开发车是 DiLink 5.1，这个功能跟固件强相关，不是所有车都有。
- **画面能调**。分辨率、帧率、图标和文字大小都能改，改完会重连一次 CarPlay。
- **诊断能导**。0.2.19 起支持用二维码或者"地址 + 验证码"把诊断报告直接下到手机上，方便去 GitHub 提 issue。
- **语言**。英语、简体中文、繁体中文、日语，加上阿拉伯语、俄语、乌克兰语、西班牙语。
- **能覆盖升级**。直接装新版本就能保留设置，公开签名密钥没变过，不用卸载重装。



## 装之前先检查

这一步最容易被忽略，但它决定了你是在折腾还是在浪费时间。

### **第一，看车机、旧手机、旧安卓平板的安卓版本。**

官方口径是 **Android 7.1 及以上（API 25+）**。

这里我得纠个偏。我看过的不少介绍文章——包括我参考的那篇源文——写的都是"Android 9 / API 28 及以上"，那是早期版本留下的旧门槛。

官方 README 现在已经放宽到 7.1+ 了，同时明确注明 7.1 到 8.1 这一段"尚未经实车验证"。

另外社区里流传"有线要安卓 9、无线要安卓 10"的说法，官方没确认过，你可以当参考，别当标准答案。

### **第二，你的车机得允许装第三方 APK。**

这条最硬，没得商量。原厂封闭车机——大众 280/866、宝马 iDrive、奔驰原厂屏这一类——系统锁死不让装第三方 APK，直接放弃，别折腾。

### **第三，你的车要是原生就有 CarPlay，装它纯属多余。**

### **第四，ADB 不是必需品。**

核心的有线、无线 CarPlay 都不需要 ADB，也不用 Root。真正要 ADB 的是那些车辆深度集成的可选功能，比如仪表数据、电池信息、车速、驻车视频。

一句话总结甜点区：**比亚迪的安卓车机 + iPhone + 原厂没有 CarPlay + 能接受偶发折腾。**

## 谁可以用

我的态度很明确，分开说：

**该试的人**——比亚迪的安卓车机、旧的安卓手机平板、主力机是 iPhone、原厂没有 CarPlay、能接受"偶尔要重连一下"的折腾。这个组合下，DiPlay 是目前性价比最高的方案，没有之一。

**别碰的人**——原厂封闭车机（装都装不上）；原生就有 CarPlay 的车（纯属多余）；指望"装完就不用管、跟原厂一样稳"的人（它是 public preview，部分车机还有卡顿、图标大小设置不生效的问题）。

还有一类我也劝退：把车机当生产力工具、导航断了会误事的人。这项目再好，也还是个预览版。

最后提醒一句：车机是长期在线设备，装任何第三方 APK 之前，先想清楚最坏情况。原车的重要数据、账号登录态该备份先备份，大不了回头重刷。



## 最后

DiPlay 这种项目最有意思的地方，不是它省了那两百块的盒子钱。

是它证明了一件事：**很多"你必须花钱买硬件才能解决"的问题，其实只是没人愿意花两周写个开源方案。**
