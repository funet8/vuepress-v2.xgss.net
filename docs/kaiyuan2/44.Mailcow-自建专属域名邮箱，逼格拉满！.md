##  课前准备

在开搞之前，这三样东西你必须准备好，否则后面绝对卡壳：

### 1. 一台靠谱的 VPS
邮件服务器比较吃内存，建议 **2核4G** 起步。

### 2. 必需开放的端口
请在 VPS 的防火墙（或安全组）放行以下端口：
`25`, `143`, `443`, `465`, `587`, `993`

### 3. 域名与 DNS 解析
准备一个域名，在你的域名服务商后台添加以下记录（**把 `yourdomain.com` 换成你自己的**）：

| 记录类型 | 主机记录 | 记录值                                              | 说明                   |
| :------- | :------- | :-------------------------------------------------- | :--------------------- |
| **A**    | `mail`   | `你的服务器IP`                                      | 指向你的VPS            |
| **MX**   | `@`      | `mail.yourdomain.com`                               | 优先级填 10            |
| **TXT**  | `@`      | `v=spf1 mx ~all`                                    | 声明谁有权用你域名发信 |
| **TXT**  | `_dmarc` | `v=DMARC1; p=none; rua=mailto:admin@yourdomain.com` | 防伪造策略             |





## 实操开始：手搓邮服之旅

### 第一步：安装 Docker 环境

如果安装了可以忽略

连上你的 SSH，如果你还没装 Docker，直接跑下面这套“一键三连”：

```bash
curl -fsSL https://get.docker.com | bash -s docker
systemctl enable docker
systemctl start docker
```
*跑完输入 `docker --version` 看到版本号，这步就算过了。*



### 第二步：拉取并配置 Mailcow
我们把项目放在 `/opt` 目录下：

```bash
cd /opt
git clone https://github.com/mailcow/mailcow-dockerized
cd mailcow-dockerized
```

接着运行配置向导：
```bash
./generate_config.sh
Detecting if your IP is listed on Spamhaus Bad ASN List...
Check completed! Your IP is clean
Press enter to confirm the detected value '[value]' where applicable or enter a custom value.
Mail server hostname (FQDN) - this is not your mail domain, but your mail servers hostname: 
```




- **Mail server hostname**：填 `mail.yourdomain.com`
- **Timezone**：填 `Asia/Shanghai`

> **💡 星哥私房秘籍（防冲突必做）：**
> 如果你服务器上装了 **1Panel** 或 **宝塔**，80/443端口肯定被占了。我们需要编辑 `mailcow.conf`，把 Mailcow 的 Web 端口改到本地：
> ```bash
> vim mailcow.conf
> ```
> 找到并修改这几行：
> ```ini
> HTTP_PORT=8080
> HTTPS_PORT=8443
> HTTP_BIND=127.0.0.1
> HTTPS_BIND=127.0.0.1
> ```
> *这样改是为了让 Mailcow 乖乖躲在本地，稍后我们用 1Panel 给它做反向代理。*

### 第三步：启动容器
```bash
docker-compose pull
docker-compose up -d
```
去泡杯咖啡，大概 3-5 分钟，用 `docker-compose ps` 看看是不是全绿（Up）了。



## 1Panel 反向代理与上 HTTPS

邮件系统没有 HTTPS 是绝对不行的，浏览器会直接拦截。这里我们借用 1Panel 来搞定。

1. 登录你的 1Panel 后台，进入 **网站 -> 创建网站 -> 反向代理**。
2. **主域名**填：`mail.yourdomain.com`
3. **代理地址**填：`http://127.0.0.1:8080`
4. 创建好后，去网站列表点 **配置 -> HTTPS**，申请一个 Let's Encrypt 的免费证书。

**关键优化（解决附件上传限制）：**

在网站的 `配置文件` 中，找到 `location /` 块，替换成下面这段，顺便把附件大小限制提升到 50M：

```nginx
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $http_host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 50M;
}
```
保存，重启网站。现在你可以优雅地通过 `https://mail.yourdomain.com` 访问后台了！



## 首次登录与“防伪”配置

### 1. 登录后台
- 地址：`https://mail.yourdomain.com`
- 默认账号：`admin`
- 默认密码：`moohoo`
> **🚨 警告：登录后第一件事，立刻改密码！**

### 2. 添加域名与建邮箱
- 左侧菜单 `Configuration` -> `Mail setup` -> `Domains`，添加你的域名。
- 切到 `Mailboxes` 标签，点击 `Add mailbox`，给自己建个邮箱，比如 `hi@yourdomain.com`，分配个 5GB 的容量。



### 3. 配置 DKIM（防进垃圾箱的终极武器）
很多新手搭完发现邮件全在对方垃圾箱，就是因为没配 DKIM！
- 在后台 `Configuration & Details` 找到你的域名，点 **DKIM** 按钮，生成并复制公钥。
- 去你的域名 DNS 后台，添加一条 **TXT** 记录：
  - 主机记录：`dkim._domainkey`
  - 记录值：`粘贴刚才复制的公钥`



## 邮件跑分

搭得好不好，不是星哥说了算，得看国际权威评分。

1. 登录你的网页邮箱：`https://mail.yourdomain.com/SOGo`
2. 打开 **Mail-Tester** (https://www.mail-tester.com/)，它会给你一个临时的测试邮箱地址。
3. 用你的新域名邮箱，给那个临时地址发一封邮件（随便写点啥，带个附件更好）。
4. 回到 Mail-Tester 点击打分。

**及格线：**

健康的邮件服务器，评分必须在 **8/10 以上**！如果是 10/10，恭喜你，你的邮局已经可以媲美大厂企业邮了，随便发邮件都不会进垃圾箱！
