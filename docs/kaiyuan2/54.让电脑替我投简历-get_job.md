# 让电脑替我投简历：9.2k 星的开源项目，AI 成本一天 6 美分

**导读：** 这篇讲一个 9.2k 星的 Java 开源项目，能把 Boss 直聘、猎聘的投递流程整条自动化。安装步骤、卡人的坑、"它为什么偏偏不能挂到云服务器上"，我都写进去了。



## 投简历最累的，从来不是写简历

找工作累在哪？

打开招聘软件，选城市，搜岗位，翻 JD，判断这公司值不值得聊，点"立即沟通"，然后等一个已读不回。

## 开源项目get_jobs

项目叫 **get_jobs**，中文名「工作无忧」，作者 loks666。

```
/loks666/get_jobs
```



Star 是随手点一下的事，但一个人愿意为了跑起来，专程去发布页下数据库文件、改名、塞进目录——那他是真的在装。

技术栈也交代清楚：后端 JDK 21 + Spring Boot 3.5，前端 Next.js 16 + React 19，数据用 SQLite 存。整套跑起来是个**网页管理台**，改配置点鼠标就行，不用碰代码。

浏览器自动化用的不是 Playwright，而是 **Patchright**——Playwright 的反检测分支。



## 它到底替你干哪几步

拆开来是四件事：

1. **搜**：按你设的城市、岗位、薪资，自己翻页找活
2. **筛**：把不活跃的 HR、猎头岗、薪资不匹配的岗位直接排除
3. **打招呼**：AI 读一遍 JD，按岗位写一句人话，不是给所有人发同一句
4. **补刀**：招呼发完自动把图片简历甩过去，不等 HR 开口要

最后这步我觉得挺聪明。

HR 那边一天收几十条"你好，我对这个岗位感兴趣"，谁省事谁先被看见。你先把简历图递过去，回复率确实不一样。

还有两个设计，看得出作者自己也在用：

- **黑名单自动更新**——回过"不合适"的公司自动进黑名单，下次不会再投第二遍
- **企业微信机器人推送**——投递结果直接推到你手机，不用守着屏幕



## AI 打一天招呼，花多少钱

配置就四行，写进项目根目录的 `.env`：

```
HOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key

BASE_URL=大模型地址
API_KEY=大模型的apikey
MODEL=大模型名称
```

`BASE_URL` 只要兼容 OpenAI 格式就行——官方的、你自己的中转、甚至局域网里跑的小模型，都能接。项目本身不绑任何代理商，这点挺干净。

`HOOK_URL` 是企业微信机器人地址。投完推一条，你今天投了几家、几家已沟通，一行看完。

这个成本结构意味着：真正贵的从来不是 AI，是你每天手动点那一百多次的时间。



## 怎么登录态

项目靠 Cookie 维持登录，作者做了「超长 Cookie」优化，正常情况下**一周扫一次码**就够。

听起来轻松，但有两个地方会咬人：

**一是升级。** README 里用加粗标了——老用户升级，千万别覆盖自己的 `db/getjobs.db`。这个文件里装着你的筛选条件、打招呼语、AI 提示词、黑名单，还有登录态。覆盖一次，全部重配。

**二是换机器。** 换电脑、重装系统、硬盘出事，那个 db 文件没备份，等于从零开始。

我自己的做法很简单：那个 `db` 目录和简历图，定期同步到一台常年不关的小机器上。投递必须在本机跑（原因后面讲），但**备份这件事没必要跟它绑在一台电脑上**。



## 安装 get_jobs

照着 README 走，整体不难。真正会卡住人的就两处。

### **第 1 步：拉代码**

```
git clone https://github.com/loks666/get_jobs.git
cd get_jobs

可以参考这个页面 ：loks666.github.io/get_jobs/guide/quick-start.html
```

国内拉得慢，作者准备了码云镜像：`gitee.com/lok666/get_jobs`。

最简单，我让workbuddy来帮我安装

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1793009179041.png?tx)

### **第 2 步：环境**

装 JDK 21 和 Gradle。程序会自动判断系统、自动下对应版本的 chromedriver，这一步基本不用管。

### **第 3 步：数据库要手动准备**

这个项目**不自动建表**，仓库里也**不带**数据库文件。

必须自己去发布页下 `getjobs.db.template`，**改名为 `getjobs.db`**，放进 `db/` 目录，最终路径是 `db/getjobs.db`。

少了这步，启动直接失败，而且报错不一定提示得那么直白。我第一次就卡在这里对着日志发了半天呆。

### **第 4 步：改配置**

浏览器打开管理页，把城市、岗位、打招呼语、AI 的 key 换成你自己的。

这里有个特别容易忽略的点：首次启动时，如果没有配置，程序会载入一份**默认配置**——那是作者本人的页面快照，里面写着上海、Java/Python/Golang/大模型方向，还有**他自己的技能介绍**。

不改就投，等于拿着别人的简历去跟 HR 聊天。

### **第 5 步：跑起来**

运行启动类 `GetJobsApplication.java` 就行。

不想起前端的话，发布页有编译好的 `dist` 包，丢进 `resources` 目录，直接起后端也能用。

如果你希望在 Boss直聘打招呼后**自动附带发送个人简历图片**：

1. 将你的 PDF 简历导出为高清单张 JPG 图片。
2. 将该图片重命名为 `resume.jpg`。
3. 放置到项目 `src/main/resources/` 目录下（最终路径为 `src/main/resources/resume.jpg`）。
4. 在系统配置中将 `sendImgResume` 项开启即可。

### **第 6步：启动后端服务**

在项目根目录下通过 Gradle Wrapper 直接启动：

**windows**

```
.\gradlew.bat bootRun
```

Linux 或者 macOS

```
./gradlew bootRun
```

```
# 也可以用 IntelliJ IDEA 打开项目，找到并直接运行：
# src/main/java/com/getjobs/GetJobsApplication.java
```



### 访问前端控制面板

- 前端已编译好的静态资源默认会直接随 release 分发，你可以直接访问本地端口（如 `http://localhost:8888` 或 `http://localhost:6680`）。
- 在网页控制台中进行关键词配置、岗位薪资限定、扫码登录平台，随后点击**“开始投递”**即可！

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1793009389025.png?tx)

### **把代理关掉。**

国内平台走墙外代理，页面加载会慢到超时，程序会以为元素没渲染出来，然后一路报错。



## 不能挂服务器上

这段我单独拿出来说，因为它跟"云"有关。

README 里作者写得很直白：**本项目不支持服务器部署，无须尝试**——招聘网站一旦识别出访问 IP 是机房 IP，直接不返回任何数据。



我们平时什么都想往云上搬：签到脚本、监控、机器人、下载器。但这套工具搬不上去，也搬不动。它的运行环境必须是——

- 一台**带图形界面**的个人电脑
- 一个**你亲手扫过码**的登录态
- 一条**没走代理**的家庭宽带 IP

三个条件凑齐，才跑得动。

换句话说，这是个天生属于"本地"的工具。有些事云真替不了你，认了吧。



## 限制

**平台只剩两个能打。** 51job 和智联作者已经停止维护了，原话一个"烂掉了，不建议使用"，一个"烂掉了，不要用"。拉钩也停了。真正在维护的只有 Boss 直聘和猎聘。

**Boss 有上限。** 每天打招呼最多 150 次，这不是软件限制，是平台限制。

**作者自己也劝你别全指望它。** 他写得很清楚：Boss 还是建议手动投递为主，这个项目当 PC 端兜底用。猎聘那边量大、成功率不高，适合铺量不适合精投。

**不能商用。** 协议是 PolyForm Noncommercial 1.0.0——自己免费用没问题，但任何形式的商业使用都禁止，想拿去卖服务得找作者拿授权。

**有人拿它骗钱。** 作者在 README 里专门写了一节，说群里有人潜伏着加好友、推收费安装、卖"一键直达"版本，已经有多人上当。这项目本身是免费的，别给人交学费。

**账号有风险。** 这类自动化本来就贴着平台规则边缘走，说完全不封号是骗人的。要不要用，自己掂量。



## 最后

工具只能把"点鼠标"这一步省掉。

它不能替你决定投哪家，不能替你判断这公司是不是坑，更不能替你面试。

投得再多，简历不行还是不行。

但反过来讲——如果你简历本来还行，只是懒得一天点两百次；如果你真正想花时间的是改项目、刷题、看机会，而不是机械地复制同一句问候语——

那这东西省下来的，是每天两小时。
