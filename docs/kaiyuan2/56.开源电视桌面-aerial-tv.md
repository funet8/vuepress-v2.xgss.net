# 电视一开机全是海报和会员弹窗？一行命令换成 tvOS 桌面，不用 root



> **导读：** 家里那台电视，开机先看三十秒广告，想找个系统设置还得在瀑布流里翻三排菜单——这事有解了。这篇讲一个开源桌面怎么换、哪些机型能装、装完怎么撤回来。



前两天刷到一篇给电视去广告的教程，底下一半留言在问同一句话：**能不能干脆把那个桌面整个换掉？**

当时没人敢给准话。冻结组件、禁自启，这些说到底都是打补丁，补丁打多了系统会闹脾气。

结果这两天再刷 GitHub，发现有人已经把这事从根上干了：**从零手写一套安卓电视桌面，装上去之后开机直接进它，原厂那套东西压根不露脸。**

项目叫 Aerial，10 月 20 号才建的仓，到今天刚满半个月。

**它不是壁纸美化软件，是替代品。** 

换完，你家电视那张脸就换了。

![封面](https://imgoss.xgss.net/picgo-tx2026/banner_aerial.png?tx)



## Aerial安装前后

不用我描述原厂桌面，你天天见。

开机先播一段会员推广，进桌面满屏都是剧集海报，"限免""影视VIP""预告"的角标到处闪，想找个自带的系统设置，得拿着遥控器在瀑布流里横着翻好几排。

![换之前：满屏海报和会员角标](https://imgoss.xgss.net/picgo-tx2026/aerial_before.jpg?tx)

Aerial 是另一套逻辑——不推内容。

正中间一张高清壁纸，左上角悬一行大号细体时钟，底下整整齐齐平铺一排常用软件。没有推广位，没有红点，没有角标。

![换之后：壁纸 + 大时钟 + 一排磁贴](https://imgoss.xgss.net/picgo-tx2026/aerial_after.jpg?tx)

注意看最后那个 Apple TV 磁贴——那是它把 HDMI 信号源也做成磁贴了，接的是游戏机就能换成 PlayStation 或 Switch 的图标。这点后面细说。



## 细节是真照着 tvOS

遥控器左右移动，选中的磁贴会平滑浮起来一点，边缘带一圈柔和的半透明光。

这玩意儿在手机屏幕截图上看不出什么，但坐在客厅三米外看，焦点在哪一目了然。**电视交互最难的就是"让人一眼知道现在选中的是哪块"，这个光晕解决了大半问题。**

按方向键，大时钟顺滑收进顶部状态栏，屏幕展开 App 网格。

有个细节挺意外：小米电视里藏得很深的原生播放器、米家这类组件，它能自动抓出高清图标平铺出来，不用你去"我的应用"里翻。

![五列网格，藏起来的系统组件也被抓出来了](https://imgoss.xgss.net/picgo-tx2026/aerial_grid.jpg?tx)

右上角按住上键，滑出一个半透明抽屉：信号源、网络、设置、睡眠，下面挂着音量和背光滑块，最底下一行小绿点是"桌面守护已开启"。

![控制中心](https://imgoss.xgss.net/picgo-tx2026/aerial_control.jpg?tx)

接游戏机的朋友会喜欢这个——换输入源点一下就到，不用退回原厂那套菜单。

长按 OK 键弹出专属菜单：移动、建文件夹、隐藏、卸载，还能设成"开机时打开"。原厂预装的垃圾软件，直接隐藏，眼不见为净。

**还有一个我觉得最实用的：手机上整理桌面。**

电视上弹个二维码，手机扫一下，浏览器里出现一个和电视一模一样的图标网格，按住拖动排序、点一下改名换图标、把 HDMI 加进主屏，全在手机上完成。

拿遥控器一个个挪图标这种反人类操作，总算有替代方案了。

**还有个功能，家里有小孩的会感谢作者：儿童与长辈模式。**

1.79 版刚加的。设一个家长密码，桌面就只显示你挑好的那几个 App。儿童模式能限每天看多少分钟、几点到几点能看、看多久强制休息一会儿；长辈模式把磁贴放大、全都带名字、焦点加白框，不容易按错。

退出要密码，进屏保或者待机后自动回到这个模式。原来那套排序、文件夹、隐藏设置一样不动。



## 屏保

说实话，界面好看只是加分项。**真正让人愿意折腾的，是屏保。**

它把 Apple TV 上那套 4K 航拍搬过来了：114 段，直接串流苹果官方 CDN，电视支持的话能播 4K 甚至 4K 杜比视界。

掠过优胜美地山谷的时候，左下角静静标着地名。按左右键随时换下一段。

![航拍屏保，左下角自动标地名](https://imgoss.xgss.net/picgo-tx2026/aerial_screen.jpg?tx)

停在主屏十秒，航拍会在磁贴后面慢慢播起来，按任意键就停在当前那一帧。

怕 OLED 烧屏的，可以切成纯黑翻页时钟，坐标每分钟微调一次避开残影。

还有个很鸡贼的设计：小米这类自带屏保的电视，它会在桌面空闲时**抢先启动**，挡在原厂广告屏保前面。

这一手不是为了好看，是为了不让那块屏在你走开的时候还替厂商打工。

## 安装之前的准备

这段是重点，别跳过。

网上不少介绍只提"支持小米、TCL、索尼"，漏了一半。实际上它发了**三个包**，适用面完全不同：

| 安装包                | 适用系统            | 什么时候用                       |
| --------------------- | ------------------- | -------------------------------- |
| `aerial-standard.apk` | Android 5.0 及以上  | 首选，先试这个                   |
| `aerial-guard.apk`    | Android 5.0 及以上  | 提示"不允许安装桌面类 App"时换它 |
| `aerial-lite.apk`     | **Android 4.0–4.4** | 老电视、老盒子专用               |

那个 Lite 版本信息量很大：家里的老电视、几年前的老盒子，只要不是太离谱，理论上都能装。

代价是没有桌面守护（主页键靠系统默认桌面）、没有航拍壁纸、没有信号源磁贴。航拍屏保、照片壁纸、时钟、文件夹、控制中心、手机配置页都还在。

**兼容性我按 README 的实测记录分三档，你直接对号：**

**放心装**：小米电视 4/4A/4X、小米盒子 4、TCL 75V2/98T8H、雷鸟 MT5879、索尼 A80J、海信 65E52D/85U7G-PRO、创维 43H30/K3 Pro、极米 H3/Z7X、当贝 Max1、腾讯极光盒子 6、斐讯 T1……

**能装但有限制**：海信 VIDAA 系列（开机多数先进聚好看）、创维 65G60 系（被清理后要等二三十秒）、TCL Q9L Pro（得用 USB 线连 adb）、极米 Z9X、部分雷鸟鹤 6。

**别折腾了**：雷鸟 75S78A Plus（固件约每分钟清一次无障碍）、雷鸟 55S595C Ultra、创维 7T641 系（黑屏或拿不到焦点）、坚果 S621、小米电视 2（Android 4.3）。

**压根不支持**：LG webOS、三星 Tizen、华为鸿蒙智慧屏。

还有一类要提前说：**老乐视、荣耀智慧屏、部分老康佳，打不开 ADB。** ADB 打不开，这套流程基本就走不通了。



## 三种安装方法，最省事甩给 AI

前提只有一个：电脑和电视连同一个 Wi-Fi，电视打开 ADB 调试。

各家开 ADB 的方式不一样，小米是"关于 → 连按产品型号"，TCL 是"本机信息 → 快速按上下左右"，海尔是机身信号源键加"左左上右"。README 里全列了，照着点就行。

### 一：让 AI 装（我最推荐）

作者专门写了一份给智能体看的安装说明。你把下面这段话丢给能跑命令的 AI（WorkBuddy、Claude Code、Codex 之类），它会自己读说明、连电视、安装、设置、最后做验收：

```text
请帮我把开源电视桌面 Aerial 装到我的电视上，并设为开机进入的桌面。
电视 IP：<填你的电视 IP>
保持 ADB 常开：要
安装说明：https://aerial.qust.me/agent.md
请先完整读完再动手，然后亲自运行命令，最后按说明里的「验收」跑一遍。
```

验收看一个东西就够：让它把 `dumpsys window | grep mCurrentFocus` 的输出贴给你，里面有 `app.orchard.tv` 就算成了。

提醒一句：手机上的豆包、网页版对话框只会告诉你步骤，不会替你在电脑上跑命令。得用能执行命令的那种。

### 二：一行命令（Mac / Linux）

```bash
curl -fsSL https://aerial.qust.me/install.sh | KEEP_ADB=1 TV=192.168.1.20 bash
```

把 IP 换成你家电视的。`KEEP_ADB=1` 的意思是——小米待机后会自动关掉 ADB，加上这个参数它会帮你重新打开，以后升级省事。

### 路子三：U 盘

APK 拷进 U 盘，插电视，用文件管理器打开装。最笨，但不需要电脑，也不需要懂命令。

想撤了，一条命令还原：

```bash
curl -fsSL https://aerial.qust.me/install.sh | TV=192.168.1.20 bash -s restore
```



## 注意

作者在文档里写得很坦诚，我照搬，不替他美化：

- **开机广告去不掉。** 那个是固件播的，桌面软件管不着。想治它得另想办法。
- **航拍走苹果 CDN 直连**，带宽低于 20 Mbps 偶尔会缓冲几秒。
- **控制中心读不到外接设备型号**，受限普通应用权限，只能显示"已连接"。
- **通电开机画面跳不过**，软件层没这个权限。
- **低配老电视会卡**。1.48 版之后它会自动切"流畅"效果（面板改纯色、去掉高光），也能手动选。

还有一条它没写但我觉得该提醒：**这类深度接管系统的工具，最好别装在老人小孩完全不会操作的那台电视上。** 万一哪天桌面守护失效，屏幕停在一个空桌面上，家里人连怎么退出都不知道。



## 谁可以装

我的判断，分三种人：

**值得装**：家里电视天天被开机海报和会员弹窗糊脸、看着就来气的；接游戏机想快速切信号源的；就想让客厅那块屏安安静静显示一张好看壁纸的。

**可以等等**：你的机型在 README 里标着"⚠️ 有限制"的。先看别人的实测反馈，或者等作者把你这型号的 issue 关掉。

**别浪费这个时间**：电视本身是华为智慧屏、三星、LG 的；或者你压根不介意那点广告，那折腾的性价比确实不高。
