## 一句话概括：把手机交给 AI，你只管下命令

`Open-AutoGLM` 本质上是一个**手机端 AI 自动化框架**。它的运行逻辑非常拟人，分为三步：

1. **👀 看屏幕**：通过实时截图 + 多模态视觉大模型（`AutoGLM-Phone-9B`），精准识别当前界面的按钮、输入框和文字布局。
2. **🧠 做规划**：AI 像人一样进行思维链推演：“现在在桌面，得先打开美团 → 找到搜索框 → 输入关键词 → 点击筛选”。
3. **👆 动手干**：通过 `ADB`（安卓）或 `HDC`（鸿蒙）底层指令，自动执行点击、输入、滑动、返回等操作，循环直到任务完成。

你只需要用自然语言说一句：`“打开美团，搜附近的重庆火锅，选评分最高的下单。”` 剩下的，它全包了。

手动安装部署。

### 第一步：环境准备（约 10 分钟）
- 电脑安装 `Python 3.10+`。
- 手机开启**开发者模式** + **USB 调试**（连续点击版本号 7 次通常可触发）。
- ⚠️ **安卓党必看**：务必安装 `ADB Keyboard` 并在系统输入法设置中启用！这是解决中文输入乱码/失效的核心。鸿蒙用户直接用原生输入法即可。

### 第二步：给 AI 装上“大脑”（模型服务）
你有两条路可选，按需自取：
- 🟢 **云端 API（推荐新手）**：无需显卡，直接调用智谱 BigModel 或 ModelScope 的已部署服务。申请一个 API Key，填上参数就能跑。
- 🔵 **本地部署（极客/企业向）**：需要 24GB+ 显存的 NVIDIA 显卡。使用 `vLLM` 或 `SGLang` 本地加载 `AutoGLM-Phone-9B`，数据不出本地，隐私与延迟双优。

### 第三步：一句指令，见证奇迹
打开终端，输入一行命令（以云端智谱 API 为例）：
```bash
python main.py --base-url https://open.bigmodel.cn/api/paas/v4 \
--model "autoglm-phone" --apikey "你的Key" \
"打开小红书搜索周末露营攻略"
```
回车，然后静静看着手机自己启动 App、点击搜索框、滑动翻页。那种“赛博朋克照进现实”的爽感，谁试谁知道！



## 避坑 Tips

跑通只是开始，想玩得更溜，记住这几条实战经验：

- 🔍 **开启 Verbose 模式**：在代码或配置中打开 `verbose=True`，AI 的“内心独白”（思维链）和每一步动作都会实时打印在终端。调试排错、学习逻辑全靠它，透明度极高。
- 🐍 **Python API 二次开发**：开发者可直接 `from phone_agent import PhoneAgent` 接入自己的业务流。配合 `Midscene.js`，还能轻松实现跨平台 UI 自动化测试。
- ⚠️ **避坑预警（重点划线）**：
  1. **数据线要选对**：必须支持**数据传输**！纯充电线会让电脑完全识别不到设备。
  2. **截图偶尔黑屏？** 别慌，通常是银行/支付类 App 触发了系统隐私保护（FLAG_SECURE）。AI 会自动切换人工接管，属于正常安全机制。
  3. **Windows 乱码报错？** 终端前加环境变量 `PYTHONIOENCODING=utf-8` 即可秒解 `UnicodeEncodeError`。
  4. **点击没反应？** 部分机型需在开发者选项里同时开启 `USB 调试` + `USB 调试(安全设置)`。
