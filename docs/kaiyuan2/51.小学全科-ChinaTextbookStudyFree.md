## 免费课程有哪些？

翻官方 Release 的资源清单时我特意数了一遍（口径来自 v1.2.0 资源包，2026 年 9 月 28 日发布）：

- **44 册教材**，2,166 个课节
- **6,545 道**单元练习题
- **779 篇**课文，支持逐句听读
- **284 篇**分级课外故事 + **1,226 道**配套阅读题
- **1,562 张**课本原页图
- **81,017 个**语音音频文件

最后那行数字，我盯着看了两秒。

八万多个音频文件，不是点个按钮就有的。做法是写脚本把全站文本全扫一遍，再用 TTS 接口批量合成，最后转码成浏览器能播的格式。**光这一包音频，压缩后就有 1.2GB。**

**题目能读，选项能读，知识讲解能读，故事也能读。**

对识字量还不大的低年级孩子，这比"再多五十道题"实在得多。





## 想自己搭一套？可以

这才是这个项目最对我胃口的地方——**它不只是一个网站，而是把源码和资源整个摊开给你了。**

三端都齐：

- **Web**：Next.js，构建完是纯静态站，扔到对象存储 + CDN 上就能跑，不需要后端
- **iOS**：SwiftUI 原生写的，iPhone 和 iPad 都支持，不是套壳网页
- **Android**：在线客户端，可以从 GitHub Actions 下调试包

作者自己那套线上站，跑的就是**私有 S3 + CloudFront**，没买云服务器，也就不存在每月固定的服务器开销。这点挺聪明，静态站就该这么放。



你想自己搭，最省事的玩法是 **workbuddy来帮我部署**：



第二种方案：Docker 家庭部署

```bash
docker compose up -d --build
```

它会自动拉资源、自动构建，Node、Python、FFmpeg 都不用你操心。

不想用 Docker，就是传统三步：装 Node 20+ 和 Python 3.9+，跑一次官方资源安装脚本（要下 2GB 出头，带 SHA-256 校验），然后 `npm run dev` 打开本地 3000 端口。

**适合谁折腾？** 家里有 NAS 或者小主机，想给孩子一个没广告、没有信息流的纯净环境——那这个真值得搭一次。搭一次，家里几个孩子能用好几年。

资源包 2GB 多，主要是存储成本，这种静态站放对象存储比放云服务器划算得多。

要用阿里云或腾讯云的，可以走星哥的渠道：**阿里云 `y.xgss.net/a`、腾讯云 `y.xgss.net/tx`**，价格跟官网一模一样。

## 飞牛 fnOS 部署步骤（Docker Compose）

### 1. 在飞牛【文件管理】新建目录

示例路径（你可以自己改）

```
/vol1/1000/Docker
```

在这个文件夹内，新建 2 个子目录：

- `html`：放 `ChinaTextbookStudyFree` 网页源码
- `pdf`：存放教材 PDF 库（TapXWorld/ChinaTextbook 的文件，可选）

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1791798156831.png?tx)

### 2. 拉取源码到飞牛的 html 目录

方式 A（推荐，电脑下载再上传）

1. 电脑访问 https://github.com/wuwangzhang1216/ChinaTextbookStudyFree
2. 点 `Code → Download ZIP`，解压全部内容
3. 把解压后的所有文件上传到飞牛 `/vol1/1000/Docker/chinatextbook/html`

方式 B（SSH 进飞牛，git clone）

```
cd /vol1/1000/Docker/chinatextbook
git clone https://github.com/wuwangzhang1216/ChinaTextbookStudyFree .
```



### 3. docker-compose.yml 编写

在 `/vol1/1000/Docker/chinatextbook` 下新建文件 `docker-compose.yml`，内容如下：

```
services:
  web:
    image: china-textbook-study-free:local
    build:
      context: .
      args:
        ASSETS_RELEASE: ${ASSETS_RELEASE:-v1.2.0-assets}
    ports:
      - "8082:8080"
    restart: unless-stopped
```



### 4. 飞牛 Docker Compose 面板创建项目

1. 打开飞牛 fnOS → 【Docker】→【Compose】→【新增项目】
2. 项目名称：`chinatextbook`
3. 文件夹路径：选择 `/vol1/1000/Docker/chinatextbook`
4. 配置文件：选择目录内的 `docker-compose.yml`
5. 勾选【创建项目后立即启动】，点【确定】，等待拉取镜像并启动容器

## 星哥试用感受下来



**一、它顶不了一整套教辅。** 前面说过，还有近 1,500 课缺知识讲解、1,183 课只有一道题。当同步练习好用，当"讲原理"的老师还不够格。

**二、题目是 AI 生成加人工校对的，不是每道题都有老师签过字。** 项目自己写明"持续接受教师复核"，说明复核还在进行中。孩子做错了，别无条件信答案，对着课本核一下。

**三、iOS 版还没上架。** 提审材料都准备齐了，但配套资源包还没发布，现在想用 iOS 端得自己用 Xcode 编译。日常使用，网页版最省事。

还得提醒一句：**清了浏览器数据或者换台设备，学习记录就没了**，因为项目本来就没做云同步。这个取舍作者写得很清楚——用便利换的隐私。
