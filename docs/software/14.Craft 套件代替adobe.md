# 不订阅 Adobe 也能修图剪片：这套 Rust 重写的开源软件，打开就是 Photoshop

> **导读：** 一个月两三百的 Adobe 订阅，很多人只用得上其中两三个功能。我把最近火起来的开源 Craft 套件实际了解了一遍——它照着 PS 的快捷键做，装完不用重新学。



## Craft 套件

这套东西叫 **Craft 套件**，开发方是 ArtCraft 团队，全部用 Rust 从零重写，代码放在 GitHub 上，**Apache-2.0 / MIT 双协议**，永久免费。

它不是一个软件，是一整排：

| 你原来用      | 对应的开源版    | 它干什么             |
| ------------- | --------------- | -------------------- |
| Photoshop     | **PhotoCraft**  | 修图、图层、蒙版     |
| Illustrator   | **VectorCraft** | 矢量、LOGO、钢笔工具 |
| Premiere Pro  | **FilmCraft**   | 多轨剪辑             |
| After Effects | **EffectCraft** | 动效、合成           |
| Lightroom     | **LightCraft**  | RAW、图库、调色      |
| InDesign      | **DesignCraft** | 画册排版             |
| Acrobat Pro   | **PdfCraft**    | PDF 拆分合并         |
| Word          | **WordCraft**   | 文字处理             |
| Excel         | **GridCraft**   | 表格                 |
| AutoCAD       | **CADCraft**    | 制图                 |
| Figma         | **FigCraft**    | 界面原型             |
| Pro Tools     | **SoundCraft**  | 音频剪辑             |
| PowerPoint    | **DeckCraft**   | 演示文稿             |

这里有个坑要先说清楚，不然你会搜错地方：**这套软件不叫 ArtCraft**。ArtCraft 是这家公司做的另一个东西，定位是 AI 图像和视频创作 IDE，走的是"先搭 3D 场景再生成画面"的路子，跟 PS 平替完全两码事。你要找的是 `storytold` 这个 GitHub 组织下面的各个 Craft 仓库。

火成什么样？截至 2026 年 10 月 27 日我查到的数据：**PhotoCraft 7.3 万星、PdfCraft 1.8 万、FilmCraft 1.6 万**，整套加起来十几万 Star。最新版 PhotoCraft 是 v0.16.0，从第一版到今天，**一共发了 18 个版本号**。启动器的 Windows 安装包，光这一个文件就被下了 **7.9 万次**。

但官方 README 自己写得很实在：**状态是 early alpha**，还明确说了"它还不是能替代日常专业工作的 Photoshop"。

这句话很重要，别被"像素级复刻"四个字带跑了。

## 它凭什么让人不学新软件？

### 1. 快捷键就是 PS 的

打开 PhotoCraft，工具栏位置、菜单层级、Ctrl+J、Ctrl+Alt+Shift+E 这些肌肉记忆，基本照搬。

官方原话大意是：**你会 PS，你就已经会用 PhotoCraft 了。**

这才是它最有价值的地方。以前用 GIMP 或者 Affinity，功能不差，但得把十年前刻进手指的记忆推倒重学一遍。Craft 套件省的是这个成本。

### 2. 它是纯原生程序，不是套壳网页

现在很多桌面软件其实是个 Electron 壳，启动一顿、内存吃一片。Craft 套件是纯 Rust 编译出来的原生二进制，底层直接吃系统图形接口（Windows 走 DirectX、macOS 走 Metal、Linux 走 Vulkan）。

体积什么水平？Windows 安装包 **71 MB 左右**，macOS 的 dmg **94 MB**。比起动辄几个 G 的创意套件，装起来心理负担小很多。

### 3. 素材不出本机

图层运算、滤镜、蒙版抠图全在本地跑，不联网、不上传。

手上有客户保密图、内部素材、不想传云的，这一条比任何功能都值钱。

### 4. 给 AI 留了后门（这条最超前）

PhotoCraft 把 **500 多条命令**塞进同一个注册表，界面、命令行、JSON 控制通道、MCP 协议**调的是同一批命令**。

意思是，你可以让脚本批量打开一批 PSD、批量套预设曲线、批量导出，全在命令行里跑完：

```sh
photocraft-cli batch --actions grade.json --in ./raw --out ./graded
```

跑 MCP 之后，AI 智能体也能直接调它内核做图层批处理。这一点比 Adobe 现在的思路要激进——**它天生是给 Agent 用的**。

## PhotoCraft 现在做到了什么程度

我挑了官方 README 里能查证的硬指标，这些数字比宣传语可信：

- **68 个工具**，Photoshop 的菜单项基本都接上了
- **16 种调整图层**，全是非破坏式，参数怎么改原图都不动；Curves 支持逐通道，Levels 带实时直方图
- **27 种 PS 混合模式**（另外还有 6 种 Paint.NET 变体）
- **1700+ 个测试**，代码分在 24 个 crate 里
- **半径 180 的高斯模糊**，在 360 万像素的图上不到 1 秒出实时预览

最要命的是 PSD 兼容。官方拿真实文件跑了三组测试：

| 测试集                         | 结果                              |
| ------------------------------ | --------------------------------- |
| psd-tools 测试集 309 个文件    | **307 个**二次保存后渲染一致      |
| psd-tools/ag-psd 混合集 170 个 | **169 个**一致                    |
| 形状图层 116 个                | **116 个**和 Photoshop 像素级匹配 |

你硬盘里攒的那堆 PSD 工程，能直接打开接着改，改完还能存回去。这一条是很多人不敢换工具的真正原因，它解决了。

再提醒一句官方自己说的：**重保存后的文件不是逐字节相同**，图层记录和合成图会被重写，但能解析的内容不会丢。

## 支持哪些平台，怎么装

这个覆盖面比想象中全：

- **Windows** 10/11，x64、arm64、x86 三种架构，有 msi 也有免安装 zip
- **macOS** 11 以上，Universal 包（M 系列和 Intel 都能跑）
- **Linux** x86_64 / aarch64，AppImage、Flatpak、deb、rpm、tarball 全给
- **FreeBSD 14**
- **网页版**，WebAssembly 跑在浏览器里，连装都不用装，应急可用

装法我建议走 **Craft Launcher**（也就是 ArtCraft Launcher）。它是个纯 Rust 写的启动器，作用和 Creative Cloud 桌面端差不多，但只有 **9 MB 左右**：

1. 去 GitHub 上 `storytold/craft-launcher` 的 Release 页，下对应系统的包
2. 打开后它会自动认出你的系统架构，列出所有 Craft 应用
3. 点一下装哪个就装哪个，有更新会提醒

界面是**带简体中文**的，跟着系统语言自动切。

安装包都附 **SHA256SUMS.txt**，下载完可以对一下校验值。

## 说点冷水：现在还替代不了 Adobe

我把官方承认的短板和实际要注意的坑都列一下，你自己判断：

**1. 完成度只到 60% 上下**

官方自评 PhotoCraft 覆盖了专业日常流程的 60% 左右，其他几个工具完成度更低。缺 **15 个工具**、缺生成式 AI 功能、缺插件兼容。

**2. 专业印刷和色彩管理是硬伤**

CMYK 精细分色、ICC 软打样，跟 Adobe 调了几十年的工业级方案还有明显差距。**做印刷出版的单子，别拿它交差。**

**3. 老插件和脚本跑不了**

`.8bf` 滤镜、ExtendScript 脚本，直接用不了。官方在换 WebAssembly 新插件架构，但现在还是空的。

**4. 格式支持有缺口**

HEIC 只读、AVIF 只能写不能读、JPEG XL 不支持，Affinity 的文件能开但存不回去。

**5. Linux 上有两个已知毛病**

Wayland 下拖文件进窗口打不开（得走"文件-打开"或者 Ctrl+V）；125%、150% 这种非整数缩放下窗口会糊。

**6. 最大的那个争议**

它是用 AI 逆向 + 净室重写的方式做的，法理上算不算干净，社区里吵得很凶。这属于你自己的风险判断，我不替你做决定。

## 谁适合现在就上

对号入座：

**建议试的**

- 自由职业者、独立摄影师、自媒体人
- 学生党、预算卡死的
- Linux 桌面用户（终于有个像样的选择）
- 家里老人的旧电脑，想装个能切图修图的

**适合的场景**

日常照片分层精修、公众号封面和海报、图标矢量绘制、视频粗剪、翻看和转存老 PSD / RAW / PDF 工程。

**别急着换的**

靠 Adobe 吃饭、每天十几个小时在里面、插件链依赖深、做印刷交付的。你可以装一份当**备用工具**，但主工作流先别动。

## 顺手提一句：版本跑得快，旧版记得留

我注意到一个细节，PhotoCraft 从 0.5 到 0.16 一共 18 个版本号，中间有过回退老版本才好用的阶段——这种早期项目都这样。

所以我的习惯是：**每个能正常跑的版本，装完的安装包不删，顺手丢一份到对象存储里**。真遇上新版翻车，回退不用满世界找。

我自己现在把这类小文件都放对象存储，一年也就几块钱，比临时抓狂强。要是你想要个稳定、便宜、还能挂自己域名的落点：

阿里云：y.xgss.net/a
腾讯云：y.xgss.net/tx

活动机一年几十百来块，跑这种备份盘绰绰有余。

这事最有意思的不是"免费替代 Adobe"，而是**一个人加上 AI，真能把行业巨头攒了二十年的东西重写一遍还开源出来**。

它现在不完美，缺工具、缺插件、专业场景有短板。但对一个只是每月切几张图、拼个封面的人来说，多一个零成本的选择，永远不亏。
