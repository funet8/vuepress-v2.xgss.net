## 什么是 MCP？

在动手之前，我们先搞懂一个核心概念：**MCP（Model Context Protocol，模型上下文协议）**。

这是由 Anthropic 提出的一种开放标准。你可以把它简单理解为 **AI 世界的“USB 接口标准”**。

就像 USB 统一了各种硬件设备的连接方式一样，MCP 统一了 AI 大模型接入各种外部工具、数据源和服务的方式。有了它，AI 就不需要为每个工具单独写适配代码了。

在 MCP 的生态里，有三个核心角色：
- **MCP Server（服务端）**：提供具体能力的“工具人”，比如文件系统、数据库、浏览器等。
- **MCP Client（客户端）**：也就是我们的 AI 助手（如 WorkBuddy），负责调用这些能力。
- **MCP 服务管理**：在 AI 工具中配置、启用和管理这些 Server 的“中控台”。

##  实操指南：如何配置 MCP 服务？

接下来是干货时间。在 WorkBuddy 中配置 MCP 主要有三种方式，总有一款适合你。

### 方法一：可视化界面配置（小白首选）

这是最直观、最推荐的方式：

1. **打开设置**：在 CodeBuddy IDE 侧边栏的对话面板右上角，点击 `CodeBuddy Settings` 齿轮图标。
2. **进入 MCP 面板**：在设置界面中，切换到 **MCP** 标签页。
3. **添加服务**：点击右侧的 `Add MCP` 按钮，系统会弹出一个 JSON 配置框供你编辑。
4. **验证运行**：配置完成后，点击 `Try to Run` 按钮，看到绿灯亮起就说明配置成功啦！

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782900978825.png?tx)



### 方法二：手动编辑配置文件（极客最爱）

如果你喜欢掌控一切，可以直接修改本地的 JSON 配置文件。
**配置文件路径**：`~/.workbuddy/mcp.json` （Windows 下通常在 `C:\Users\你的用户名\.workbuddy\mcp.json`）

MCP 支持两种通信类型，配置示例如下：

**1. stdio 类型（本地命令执行）：**
```json
{
  "mcpServers": {
    "python-tools": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "my_mcp_server"],
      "env": {
        "PYTHONPATH": "/path/to/tools"
      },
      "description": "Python 工具集"
    }
  }
}
```

**2. sse 类型（HTTP 远程服务）：**

```json
{
  "mcpServers": {
    "filesystem": {
      "type": "sse",
      "url": "http://localhost:3000/sse",
      "description": "文件系统访问"
    }
  }
}
```

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782901131962.png?tx)

### 方法三：自然语言自动配置（魔法时刻）

这也是 WorkBuddy 最让我惊艳的功能——**你甚至不需要懂 JSON！**

你只需要在对话框里用大白话告诉它你的需求，比如：
> *“我想让 AI 能读写我的本地 C 盘文件，顺便帮我配一个 Playwright 浏览器自动化。”*

WorkBuddy 会瞬间理解你的意图，并**自动生成**如下配置代码，你只需确认即可：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:/Users/YourName"]
    },
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```
**配置完还能直接问它**：“查询一下本机 MCP 配置情况”，它会乖乖把当前已启用的服务、访问目录、运行方式甚至配置时间都汇报给你。
