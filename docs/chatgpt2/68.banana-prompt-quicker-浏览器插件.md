## 什么是 banana-prompt-quicker？

简单来说，这是一个能让你 **“告别复制粘贴，实现提示词一键注入”** 的浏览器扩展。

它内置了丰富的优质提示词库，并且深度适配了 Gemini 的各大生图渠道。你不需要再手动去复制那些长长的英文提示词，只需轻轻一点，或者一个右键，提示词就能精准插入到输入框中，让你的生图效率直接翻倍！

## 核心亮点

这款扩展之所以好用，不仅仅是因为“能插入”，更是因为它在细节上做到了极致。星哥给大家总结了几个最核心的亮点：

### 全场景覆盖， anywhere 都能用

它不仅完美支持 **Gemini 官网**、**Google AI Studio** 和 **Gemini Enterprise**，甚至还支持了 **kokorolab** 等垂类生图网站。 更绝的是，它支持**任意网站的任意输入框**！只要你在网页上，右键选择【🍌 Insert Banana Prompts】，就能直接调用提示词画廊并插入，真正做到了“随时随地，想生就生”。

### 独创“灵光模式”，选择比填空容易

对于新手或者偶尔“词穷”的朋友，它的“灵光模式”简直是救星。 你不需要从零开始填空，系统会引导你通过“做选择题”的方式，一步步拼凑出专业的生图需求。加上内置的**随机排序**功能，每次都能给你不一样的灵感盲盒。

### 进阶玩法：支持参考图与高度自定义

到了 V1.6.0 版本，它已经进化得非常强大了：

- **支持添加参考图**：提示词结合参考图，出图更精准。
- **自定义提示词**：你可以把自己珍藏的独家 Prompt 添加进去，打造个人专属词库。
- **NSFW 过滤**：贴心加入了安全过滤功能，适合在办公或公共环境下使用。



## 如何安装banana-prompt-quicker？

安装过程非常简单，星哥给大家整理了三种方式，总有一款适合你：

### **方式一：Chrome 应用商店安装（最推荐）** 

直接在 Chrome 网上应用店搜索 `banana-prompt-quicker`，或者点击官方链接一键添加至 Chrome 即可。

复制放到谷歌浏览器中： chromewebstore.google.com/detail/banana-prompt-quicker/hgfgfocicepifbolifedlokjkknigoid?authuser=0&hl=zh-CN

添加至Chrome，即可。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782727070815.png?tx)

### **方式二：手动解压安装（适合开发者）**

1. 下载或 Clone 项目仓库。
2. 浏览器访问 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目根目录下的 `extension` 文件夹。



### **方式三：移动端用户看这里** 

手机端推荐使用 **Cronmite** 浏览器。在 Cronmite 中打开 Chrome 商店的链接，点击「添加至 Chrome」就能在手机上愉快地使用了。
