## 它到底怎么做到给 Codex 换脸的？

先说结论：**没动 Codex 一根毫毛。**

Codex 桌面端本质是个 Electron 应用，界面用 Web 技术渲染。正常来说，官方没开放换肤接口，你想改？没门。

但这个项目绕了个弯。

它用 Chrome DevTools Protocol（CDP）协议，在 `127.0.0.1` 本机回环地址上，往 Codex 的界面里注入自定义的 CSS 和 JavaScript。

翻译成人话就是：**在 Codex 原生界面上面叠了一层装饰膜。**

这层膜有几个特点，我觉得必须说清楚：

- **不走外网。** 所有通信都在本机回环，你的代码、你的 API Key，一个字节都不会往外漏。
- **不碰官方安装包。** `.app` 二进制没动，`.asar` 资源包没动，签名完好。Codex 该更新更新，完全不受影响。
- **一条命令能恢复。** 跑一下 Restore 脚本，立刻回到原厂状态，干净得像什么都没发生过。

原理其实不复杂，就是 DevTools 写 CSS 的自动化加强版。但放在 Codex 上，愣是被做成了一个完整的主题引擎。

## 零基础怎么搞？两句话的事

分两步走，全程不用你写一行代码。

### 第一步：装主题引擎。

打开 Codex，在对话框里直接输入：

> 用这个开源项目帮我替换 Codex 主题 https://github.com/Fei-Away/Codex-Dream-Skin

AI 会自动帮你做五件事：克隆仓库、检查 Node.js 版本（需要 18+）、识别你的操作系统、选对脚本执行安装、跑一遍默认主题验证环境。

首次大概两三分钟，全程看着就行。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1784798782553.png?tx)

### 第二步：定制你自己的主题。

装好之后，直接跟 AI 说你要什么风格：

> 帮我生成火影忍者佐助的主题素材，包括背景图、侧栏暗纹和装饰元素

AI 会直接生成图片并自动套用。哪里不满意，继续说：

> 侧栏配色太暗了，换深蓝色。输入框边框太突兀，调细一点。



AI 自己去改 CSS，你只管提需求。

**想恢复原样？** 跑 Restore 脚本，一条命令的事。



## 几个大家关心的问题

**安全吗？**

CDP 只绑定 `127.0.0.1`，主题运行期间别乱跑来历不明的本机程序就行。它不会自动改写你的 API Key 和 Base URL，中转和换肤是两码事。

**Mac 和 Windows 都支持吗？**

都支持。Mac 双击 `Install Codex Dream Skin.command` 就行，Windows 跑两个 PowerShell 脚本。仓库里按平台分好了目录，README 写得很细。

**会影响 Codex 更新吗？**

不会。官方安装目录和代码签名完全没动，更新照走。

**素材版权呢？**

仓库预设里的人物和 IP 素材只是主题示意。如果你要商用或者公开再分发，肖像权和素材权利得自己确认。
