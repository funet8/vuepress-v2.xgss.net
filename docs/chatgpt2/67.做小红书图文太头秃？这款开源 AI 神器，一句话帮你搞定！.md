它的核心逻辑非常简单粗暴：**你只需要输入一句话（比如：“分享 5 个提升效率的 Mac 软件”），它就能自动帮你生成大纲、封面，甚至批量生成所有内页的图片！**

项目作者“默子”是一位在杭州创业的 AI 开发者，整个项目做得非常精致，不仅逻辑顺畅，而且审美在线。

### 核心玩法：三步搞定爆款图文

RedInk 的工作流设计得非常符合人类直觉，主要分为三步：

### Step 1：智能大纲生成 

输入你的核心主题后，AI 会瞬间生成一份结构清晰的大纲。 **星哥划重点**：这里的内容是**完全可编辑**的！你可以随意调整页面顺序，或者自定义每一页的描述，确保内容完全符合你的个人风格。

### Step 2：封面页生成 

小红书能不能火，封面占一半！RedInk 生成的封面不仅**文字准确无误**，而且**视觉风格高度统一**。它会根据你的主题自动匹配最合适的排版和配色，告别土味封面。

### Step 3：内容页批量生成

这是最爽的一步！点击生成后，系统会**并发处理**，一次性帮你把剩下的内页（默认最多 15 张）全部画出来。 如果某一张图不满意？没关系，支持**单张图片重新生成**，而且会自动保持上下文风格一致，不会让你觉得“画风突变”。



## Docker 一键部署，丝滑上车

作为“星哥玩云”的老读者，大家都知道星哥最推崇的部署方式就是 **Docker**。RedInk 对 Docker 的支持非常完美，一行命令就能搞定！

### 1.docker一键部署

**前置准备**：一台能联网的服务器或本地电脑，安装好 Docker。

```
新建目录
mkdir -p /data/docker/redink
cd /data/docker/redink
```

**一键启动命令**：

```
启动命令：
docker run -d -p 12398:12398 \
  -v ./history:/app/history \
  -v ./output:/app/output \
  histonemax/redink:latest
```

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782718431930.png?tx)

### 2.浏览器访问

运行后，直接在浏览器访问 `http://localhost:12398`（如果是服务器，就换成你的 IP）。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1782718464657.png?tx)

**星哥提示**：

1. 容器内**不包含**任何 API Key，你需要在 Web 界面的“设置”页面自己填入。
2. 命令中的 `-v` 参数是为了持久化你的历史记录和生成的图片，千万别漏了，否则重启容器数据就没了！
