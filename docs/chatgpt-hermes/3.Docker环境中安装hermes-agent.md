# Docker环境中安装hermes-agent



## 服务器和环境准备

如果你准备部署在 **Linux 云服务器 / Ubuntu / Rocky Linux** 上，我建议直接用 Docker Compose。

## 安装hermes-agent

### 1.创建目录

```
mkdir -p /home/data/docker/hermes/data
cd /home/data/docker/hermes
```

官方设计中，/opt/data 是 Hermes 的持久化数据目录，里面会保存 API Key、配置、Session、Memory、Skills、Cron 等，所以一定要挂载出来。



### **2. 创建** docker-compose.yml

```
services:
  hermes:
    image: nousresearch/hermes-agent:latest
    container_name: hermes
    restart: unless-stopped
    command: gateway run
    ports:
      - "8642:8642"
      - "9119:9119"
    volumes:
      - ./data:/opt/data

    environment:
      HERMES_DASHBOARD: "1"
      HERMES_DASHBOARD_BASIC_AUTH_USERNAME: "admin"
      HERMES_DASHBOARD_BASIC_AUTH_PASSWORD: "S123456"

    deploy:
      resources:
        limits:
          memory: 4G
          cpus: "2.0"
```



官方 Compose 示例也是 gateway run，并使用 /opt/data 持久化；

Dashboard 使用端口： 9119

Gateway API 使用端口： 8642。

```
HERMES_DASHBOARD_BASIC_AUTH_USERNAME: "换成自己的账号" 
HERMES_DASHBOARD_BASIC_AUTH_PASSWORD: "换成自己的账号"
```



### 3. 第一次启动，先运行初始化向导

不要直接启动 Gateway，先执行：

```
cd /home/data/docker/hermes

docker run -it --rm \
  -v /home/data/docker/hermes/data:/opt/data \
  nousresearch/hermes-agent setup
```



然后按照向导配置模型 API Key。

配置完成后，应该可以看到：

```
cat /home/data/docker/hermes/data/.env
```

里面会保存 Hermes 的相关配置和 API Key。官方文档也明确说明，首次部署应该先运行 setup。



### 4. 启动 Hermes

```
cd /home/data/docker/hermes

docker compose up -d
```



查看：

```
docker compose ps
```



日志：

```
docker compose logs -f hermes

或者：

docker logs -f hermes
```



### 5. 检查容器

```
docker ps

应该类似：

CONTAINER ID   IMAGE                              STATUS xxxxxxx        nousresearch/hermes-agent:latest  Up ...

```

检查版本：

```

docker run --rm \
  -v /home/data/docker/hermes/data:/opt/data \
  nousresearch/hermes-agent version
```





### 6. Dashboard

如果开启：

HERMES_DASHBOARD: "1"

那么会监听：9119

Gateway API：8642

不过**不建议直接把 8642/9119 暴露到公网**。官方文档也特别提醒，直接开放公网端口存在安全风险。
