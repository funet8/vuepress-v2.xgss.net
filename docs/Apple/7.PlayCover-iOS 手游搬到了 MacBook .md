# 128G手机被游戏占满？我把 iOS 手游搬到了 MacBook 上

**导读：** 手机内存天天告急，游戏又舍不得删。这篇讲怎么用 PlayCover 在 M 芯片的 Mac 上原生跑 iOS 手游——键盘鼠标操作，数据跟手机互通，不用装模拟器。读下来 6 分钟，动手 10 分钟能装完。



## 我这台 128G 的手机，快被游戏吃干净了

心情不好的时候我就想开一把，听那声熟悉的 "TIMI"。

问题是，我手里这台 iPhone 16 是 128G 的。还没装几个游戏，光系统加照片就占了 80 个 G，再往上堆就要触发存储告急了。

删游戏？舍不得。

换手机？为了玩游戏多花两千块升容，我觉得不太值。

后来我想通了一件事——我桌面上那台 MacBook Pro，性能比手机强出一大截，为什么游戏非得在手机上跑？

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1789544338478.png?tx)



## Mac 能玩 iOS 手游，口子是苹果自己留的

M 系列芯片出来之后，这事其实就成立了。

M 芯片跟 A 芯片是同一套 ARM 架构，说白了是亲戚。

理论上，所有 iOS 应用都能在 Mac 上跑起来——不需要虚拟机，不需要模拟器，原生运行，性能直接吃满。

这个功能当年是真的香，但它动了 App Store 的蛋糕：你在 Mac 上白嫖手游，苹果一分抽成拿不到。

结果就是被苹果按掉了。你现在去 Mac App Store 里搜手游，搜不到，直接屏蔽。

不过苹果留了个后门：**macOS 是允许应用侧载的**（iOS 不行）。

所以这条路一直有人在走。

想要键鼠玩 iOS 手游首选 **PlayCover**；

不想折腾 IPA 就用「**iPhone 投屏**」；

游戏开发商开放的直接 Mac App Store 装是最稳的官方方案。



## PlayCover：社区接管的开源方案



**PlayCover 是开源免费工具，仅 Apple Silicon Mac（M1/M2/M3/M4…）可用，Intel Mac 不支持**，作用是在 macOS 原生运行 iOS/iPadOS 应用与手游，不是传统虚拟机，是包装层（wrapper）模拟 iPad 环境，性能接近原生，最初为 Mac 玩《原神》开发PlayCover。

它的原理不复杂：给应用套一层"假装自己是 iPad"的外壳，让 iOS 应用以为自己跑在 iPad 上，然后就能原生执行了。

几个关键点：

- **完全开源免费**，GPL-3.0 协议，社区在维护
- **原生 ARM 性能**，比安卓模拟器轻太多了
- **支持 120 帧**
- **键鼠映射**，这点是 Sideloadly 那类工具做不到的
- **不用 Apple ID**，也不需要越狱

限制也很明确：**只支持 Apple Silicon，也就是 M1 及以后的芯片**。Intel 的 Mac 请直接绕道。



## 第一步：下载安装 PlayCover

官方下载页（Release 页面）：

```
https://github.com/PlayCover/PlayCover/releases
```

进去挑最上面那个版本的 **.dmg** 文件下载（Assets 区域里）。

装的时候有个坑要注意：**必须把 PlayCover 拖到「应用程序」文件夹里**。

放桌面或者别的地方，它会起不来。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1789544418956.png?tx)

喜欢用命令行的，Homebrew 也行：

```bash
brew install --cask PlayCover/playcover/playcover-community
```

第一次打开会被系统拦下来，右键点图标选"打开"，或者去「系统设置 → 隐私与安全性」里点一下"仍要打开"。这类开源应用都会遇到，正常操作。



## 第二步：给它加一个 IPA 源

PlayCover 本身是个空壳子，里面什么都没有，你得喂它 IPA。

IPA 就是 iOS 应用的安装包，相当于 Windows 上的 exe。

我常用的源是这个：

```
https://decrypt.day/library/data.json
```

操作路径：打开 PlayCover → 左侧切到「IPA 资源库」→ 点顶部的加号 → 把这行地址粘进去。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1789544446207.png?tx)

**出现绿色对勾就说明源通了。**

这类第三方 IPA 站点起起落落很正常，哪天不好使了别慌，官方文档里还列了备选：`ipa.un3fy.dev`、`ipastore.app`、`armconverter.com`，多存几个心里踏实。



## 第三步：搜游戏，双击装

源加好之后，用起来就跟应用商店一个手感。

在资源库右上角的搜索框敲游戏名，找到最新的 IPA，**双击**，等进度条走完。

原神、王者、金铲铲这些热门的都有，更新也挺勤。

装完在列表里双击启动。第一次进游戏会慢一点，别急着杀进程，等它自己起来。

进入游戏之后，**按一下 Option 键**就切进键位映射模式了。



## 三个必踩的坑，提前说清楚

### 坑一：更新

手游更新有多勤大家都知道，而且带联网校验，版本不对直接把你踢出来。

- **小版本更新**：一般能在线更新，省事
- **大版本更新**：得重新下 IPA，覆盖安装一遍

好消息是覆盖安装不会丢账号和存档，重新装一遍数据还在。

### 坑二：键位映射

这是 PlayCover 最大的痛点。开源项目嘛，现成的键位方案少得可怜。

默认那套智能映射要是用着别扭，就得自己动手：

1. 进游戏按 Option 开始配
2. 或者去网上搜别人做好的键位方案
3. 右键 App → 导入键位 → 自己再微调

WASD 走位、鼠标转视角、左右键开火，配顺手了跟打端游没区别。免费的东西嘛，总得花点时间调。

### 坑三：一进去就闪退

这是最常遇到的问题。

有些 App 自带签名检测机制，一看你不是从 App Store 装的，立刻闪退。

解法：用 **Sideloadly** 或者**爱思助手**重签一遍就好了。唯一的麻烦是免费证书 7 天到期，到期得再来一次。



## 几句实在话

用之前，有三件事你得先知道：

1. **账号风险**。带强反作弊的竞技类手游，有可能检测到 PlayCover 然后封号。这事官方文档也明说了，风险自负，别拿主力号去试。
2. **它不是模拟器**。PlayCover 是 iPad 容器，所以只能跑 iOS 上本来就有的东西，PC 独占的游戏跑不了，别指望它当 Windows 游戏机使。
3. **谁适合用**。手机 128G 常年爆红、手里又正好有台 M 芯片 Mac 的，这套方案非常值。反过来，你要只有 Intel Mac，就别折腾了。



## 最后聊两句

PlayCover 这套东西，说起来也就三步：装软件、加源、双击装游戏。真正的门槛全在那些坑里——键位调不顺、签名到期闪退、版本更新要重装。
