# Mac苹果系统越用越慢？那些偷偷自启的东西，这个 3.7MB 开源工具全给你揪出来

> **导读：** 一台 Mac 用上两年，开机越来越慢、风扇莫名其妙就转、合盖一晚上掉 20% 电——很多人以为硬件老了，其实是后台自启项攒了一堆。系统设置只给你一句“后台项目”，剩下什么都不说。这篇讲一个开源小工具怎么把四层藏身地一次翻起。



## Birth的作用

Birth 是一款免费开源的 macOS 启动项管理工具。它把系统里每一个后台项、守护进程和登录项收进同一个窗口，告诉你*是谁装的*（代码签名身份）、现在有没有在运行，并让你一键停用或移除。

它干的事用一句话说：把散在四个机制里的启动项，收进同一个窗口。

| 藏身地                   | 住着谁                 | 系统设置告诉你吗         |
| ------------------------ | ---------------------- | ------------------------ |
| `~/Library/LaunchAgents` | 你自己账号下的后台项   | 只显示成“后台项目”       |
| `/Library/LaunchAgents`  | 全机器所有用户的后台项 | 同上                     |
| `/Library/LaunchDaemons` | root 权限的守护进程    | 同上                     |
| BTM 登录项               | 开机自己弹出来的 App   | 显示，但没有路径没有细节 |

系统设置不肯说的那部分，恰好是最关键的部分：**plist 在哪、指向哪个可执行文件、谁签的名。**

第三方软件的更新器、辅助进程、装完不走的卸载残留，恰恰就靠这点不透明活着。

项目取名叫 Birth 是有点浪漫在里面的：**launchd 是 PID 1，Mac 上每一个进程都是从它那儿生出来的。启动项就是这台机器的出生仪式，谁有资格留下，你该有决定权。**

这话我很喜欢。电脑是你的，开机跑什么，理应由你说了算。

## Birth 主要干的事

我看完了 README 和它全部的 issue，挑几个真能让它跟“手工翻目录”拉开差距的点说。

### 一、一屏四层，默认只看第三方

打开高级那一栏，用户后台项、全局后台项、守护进程、登录项四层并排列出来。

默认只显示第三方——这个默认值很聪明。苹果自己的东西你不用管，你要揪的就是外面塞进来的那堆。想全看，一键切换。

而日常用的“启动应用”页，**打开就能看，一个授权框都不弹。**

这点值得单独说。macOS 上同类工具大多一上来就要你给一堆权限，给完你也不知道它拿去干嘛。Birth 是反过来的：**能看的先给你看，要动手了才要权限。**

### 二、最狠的一招：它告诉你“谁签的名”

功能表里有一条，我觉得是这个工具真正的价值所在：

**它会去验证代码签名的证书链，给你七个判定——Apple、App Store、已识别开发者、不受信任的证书、临时签名、未签名、签名无效。**

再配一条**伪装检测**：如果一个东西把标识符写成 `com.apple.xxx` 冒充系统组件，但签名对不上，它会打一个红色的“伪装系统项”。

为什么要专门做这个？

因为伪装成苹果系统进程，**是恶意软件留在你电脑上最常用的手法，没有之一**。它就赌你不会去翻 `/Library/LaunchDaemons` 里那个叫 `com.apple.softwareupdated` 的 plist，赌你看见 `com.apple` 三个字就放心了。

普通的进程管理器，名字一列，你根本分辨不出来。Birth 是直接把签名摆你脸上。

**不过作者自己写得很实在：这个徽章证明的是“身份”，不是“完整”。** 它验证是谁签的，不做全量内容哈希——那是 Gatekeeper 的活儿。这话我原样转给你，别把签名绿了当成绝对安全。

### 三、输入一个 PID，反查是谁拉起来的

活动监视器里看到一个占 CPU 的陌生进程，PID 是 3821。

你把它输进 Birth 的搜索框，它直接告诉你：**这个进程是哪个启动项拉起来的。**

这个场景太真实了。平时排查这种问题，得 `ps` 出来看父进程，再顺着往上找，一路找下去还不一定找得到根。

现在一步到位。

另外它按名称、开发者、路径都能搜，五列表头点一下排序，排序列和方向跟访达一样记着，下次打开还是那样。

### 四、删东西之前，先给你备份

这条是我最看重的。

它的删除不是“点一下就没”：**先把任务停掉，plist 扔进废纸篓，同时在 `~/Library/Application Support/Birth/Backups` 留一份备份。**

还有专门的“最近移除”页面。手滑删错了，一键加回来。

凡是这种能改系统底层配置的工具，有没有撤销，是我判断它能不能用的第一条线。**没有后悔药的工具，再强我也不敢碰。**

顺带它还带个 plist 查看器，二进制格式自动转成能读的 XML，想自己核对内容随时看。



## 怎么安装birth

### 方式一，下 DMG（大多数人走这条）：

1. 打开 `github.com/iAmCorey/birth/releases`
2. 下最新的 `Birth-x.x.x.dmg`（universal 包，M 芯片和 Intel 都能跑）
3. 拖进“应用程序”文件夹
4. 首次打开如果被拦，去 系统设置 → 隐私与安全性 → 页面底部点“仍要打开”

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1793253297561.png?tx)

### **方式二，自己编（有开发环境的走这条）**

```bash
git clone https://github.com/iAmCorey/birth.git
cd birth
./scripts/make-app.sh
open dist/Birth.app
```



想编双架构通用包，加个参数：`./scripts/make-app.sh universal`。

### **卸载**

把 App 拖进废纸篓就行。想清干净，再跑两行：

```bash
defaults delete dev.birth.Birth
rm -rf ~/Library/Application\ Support/Birth
```

别忘了去系统设置里把给它的权限删掉。



**最后提醒一句：只从 GitHub 的 Release 页下。** 这类系统工具一旦被二次打包，里面塞点东西你根本看不出来，而它偏偏又拿着完全磁盘访问权限——这个组合太危险了。



## 权限设计

我把官方那张权限表贴出来，你自己看合不合理：

| 你要干什么                    | 需要什么权限 | 什么时候要           |
| ----------------------------- | ------------ | -------------------- |
| 看“登录时打开”的 App 列表     | 不要         | —                    |
| 浏览用户/全局后台项、守护进程 | 不要         | —                    |
| 启停用户级、全局级的后台项    | 不要         | —                    |
| 添加/移除登录 App             | 自动化授权   | 第一次改的时候弹一次 |
| 查看“登录项”分类              | 完全磁盘访问 | 去系统设置勾一次     |
| 启停守护进程、删全局项        | 管理员密码   | 每次操作             |

**“用到才要，要一次就够”**，这是它 README 里的原话。

不给权限也不至于废掉，界面里会告诉你缺什么、去哪儿开，开完切回来自动刷新，之后就不吭声了。

新增登录 App 除了走菜单，还能**直接把 App 拖进窗口**。这个交互我挺喜欢，符合 Mac 的习惯。

## 注意的点

好话说完了，该浇冷水。下面这些官方自己写在 README 里，我一条没漏：

### **1. 它没有苹果公证**

个人开源项目，买不起或者懒得买开发者账号走公证流程。第一次打开会弹“无法验证开发者”，你得去 系统设置 → 隐私与安全性，在页面底部点一次**“仍要打开”**。

就一次。但这确实是道坎，胆小的人到这儿就退回去了。

### **2. 升级一次，权限要重新给一次**

它现在是 ad-hoc 临时签名，每构建一次签名身份都变。所以：升级到新版本后，**完全磁盘访问和自动化授权得在系统设置里重新勾一遍**（把开关关了再开）。

同一个版本里授权一次是长期有效的。但每次升级都得来这么一遍，有点烦。

### **3. “登录项”那一栏只能看不能改**

macOS 没给第三方开放切换这类项目的 API，作者也没辙，只能给你一个一键跳到系统设置的按钮，剩下的你自己点。

这不是偷懒，是苹果把门锁死了。

### **4. 签名徽章不等于安全认证**

上面说过，再强调一次：它验的是“谁签的”，不是“内容有没有被动过”。真正的完整性校验在 Gatekeeper 手里。

### **5. 只有 macOS 14 以上能用**

Sonoma 起步。老系统，对不起，没你的份。

### **6. 这个项目目前停在 8 月底**

最新版本是 8 月 29 日的 v0.2.11，已经两个月没更新了。

issue 区还挂着一条没人接的——有人想要 Homebrew 安装源。

不是说不维护了，但这种个人项目，节奏本来就随作者心情。

**你要用它管系统底层配置，心里得有个数：哪天它不更新了，你得自己接手。**



## 安装建议

**建议装的：**

- Mac 上软件装得多的，尤其是那种“装过一堆又删了一半”的
- 开机慢、风扇爱转、合盖掉电快的
- 帮家里人、同事修电脑的（这工具排查效率最高）
- 有洁癖，想知道自己机器上到底跑着什么的

**可以再等等的：**

- 系统版本在 macOS 13 及以下的，装不了
- 一点不想碰系统底层配置的，这工具对你来说风险大于收益
- 公司电脑有 MDM 管控的，别乱动，IT 会来找你

说句实在的：**它不是一个“一键优化大师”。** 它不会帮你决定该关谁，它只负责把真相摆清楚。

真正有价值的是它给你的判断依据——签名、路径、PID、装它的那个 App。剩下那一刀，还得你自己下。
