## 为什么你需要一个 Applite？

很多新手朋友不知道，Mac 上很多好用的软件，其实并没有上架苹果官方的 App Store。

比如大家最常用的 **Google Chrome** 和 **Microsoft Edge** 浏览器，在 App Store 里是搜不到的。



那怎么办？以前大家的做法是去官网下，然后手动去系统设置里解除安全限制，折腾半天。

但现在有了 Applite，事情就简单多了。

打开 Applite 的“发现”页面，Chrome、Edge 这些主流浏览器直接就能一键下载安装。除了浏览器，它还把软件分门别类整理得明明白白：

生产力工具、办公神器、菜单栏小工具、开发终端、甚至 VPN 和密码管理器，应有尽有。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785309876910.png?tx)



说白了，它就是一个懂你的 Mac 第三方软件管家，填补了 App Store 软件太少的空白。



## 告别命令行

提到 Mac 上的第三方软件管理，懂点技术的朋友可能会想到 **Homebrew**。

但 Homebrew 毕竟是个命令行工具，满屏的代码和英文指令，对非技术人群实在不太友好。

Applite 的聪明之处在于，它底层使用了 Homebrew，但表层却做了一套极其干净、简洁的图形界面。它不想做一个复杂的代码包装器，只想做一个纯粹的应用商店。



**它最大的亮点，星哥给大家总结了几个：**

### **傻瓜式一键操作**

安装、更新、卸载软件，再也不用敲 `brew install` 这种命令了。鼠标点一下，剩下的交给它。

### **对小白极度友好**

界面设计非常克制，没有乱七八糟的广告和冗余功能，找软件、装软件一目了然。

### **完全免费且开源**

这点必须点赞！代码完全透明，没有隐藏的收费套路，用着踏实。

### **细节拉满**

支持系统代理（HTTP/HTTPS/SOCKS5），网络环境复杂的朋友也能顺畅下载；而且内置的软件库都是精挑细选的，质量很高。



## 保姆级安装与使用指南

说了这么多，怎么把它装进你的 Mac 里呢？星哥给大家准备了保姆级教程。

### 第一步：下载安装

最简单的方法，就是直接去它的 GitHub 官网（星哥把链接放文末了），下载 `.dmg` 安装包。

下载后双击打开，把 Applite 拖进“应用程序”文件夹就搞定了。

![img](https://imgoss.xgss.net/picgo-tx2026/QQ_1785310029673.png?tx)

如果你是 Homebrew 的老玩家，也可以直接在终端里敲一行代码：

`brew install --cask applite`



### **第二步：首次启动设置**

这里有个小细节要注意。



第一次打开 Applite 时，它会检测你的电脑里有没有 Homebrew 环境。
- **如果你是老手**：之前已经装过 Homebrew，直接选“继续”，它就能接管你现有的软件。
- **如果你是纯小白**：选择 **“为 Applite 安装独立的 brew”**。它会在后台自动帮你把环境配好，你只需要喝口咖啡等它跑完就行。

市面上其实也有类似 Cork 或者 Brewer X 这样的图形化工具，但它们大多是收费的。相比之下，免费又好用的 Applite，在易用性上绝对更胜一筹。
